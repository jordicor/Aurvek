## Kurzantwort

Aurvek ruft Ihre verifizierte Profilnummer sofort oder geplant an. Bei aktivierten eingehenden Anrufen können Sie von dieser Nummer anrufen und den zugewiesenen Chat fortsetzen. **Ruf mich an** nutzt das Telefonnetz, **KI-Stimme** das Browsermikrofon.

## Schritte

1. Unter **Einstellungen > Profil** Telefonnummer verifizieren. Eine gespeicherte **Zeitzone** hilft dem Assistenten, Zeitwünsche zu verstehen.
2. Gewünschten Chat öffnen, **+ > Ruf mich an** wählen.
3. **Diese Unterhaltung für Telefonanrufe verwenden** wählen. **Jetzt anrufen** und **Für später planen** weisen sie ebenfalls automatisch zu.
4. Sofort oder Datum/Uhrzeit wählen. Die Auswahl nutzt die aktuelle Browser-Zeitzone. Aurvek ruft nur die gespeicherte Profilnummer an.
5. Bietet Ihr Konto eine Nummer für eingehende Anrufe, rufen Sie von Ihrer verifizierten Nummer an. Prompt und Verlauf stammen aus dem zugewiesenen Chat.
6. Falls vom Prompt erlaubt, den Assistenten natürlich um sofortigen oder geplanten Anruf bitten. Ohne gespeicherte Zeitzone fragt er ggf. nach Stadt und Land.
7. Unter **Einstellungen > Anrufe** Verlauf sehen oder ausstehenden Termin stornieren. Sie oder der Assistent können laufende Anrufe beenden.

## Hinweise

- Pro Konto ein zugewiesener Telefonchat; eine neue Zuweisung ersetzt ihn.
- Telefon ist unabhängig von WhatsApp/Telegram: Ein Chat kann Telefon plus einen Messaging-Kanal nutzen.
- Nur ein künftiger Anruf gleichzeitig; einmalig, nicht wiederkehrend.
- Das Transkript wird im Chat gespeichert. Roh-Audio bleibt standardmäßig nicht erhalten; ein Prompt kann Aufbewahrung ausdrücklich aktivieren.
- Dienstverfügbarkeit und Guthaben erforderlich. Gesperrte/Inkognito-Chats können keine Anrufe starten oder planen.
