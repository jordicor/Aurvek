## Kurzantwort

Verzweigen Sie eine Unterhaltung ab einer beliebigen Nachricht. Ein unabhängiger neuer Chat enthält alle Nachrichten bis zu diesem Punkt. So erkunden Sie eine andere Richtung und behalten den ursprünglichen Verlauf.

## Schritte

1. Maus über eine Nutzer- oder Botnachricht im Chat bewegen.
2. **Verzweigungssymbol** (Code-Verzweigung) bei den Nachrichtenaktionen anklicken.
3. Ein Dialog fragt, ob ab dieser Nachricht eine neue Unterhaltung entstehen soll.
4. **Bestätigen** anklicken. Alle Nachrichten bis einschließlich der gewählten werden kopiert.
5. Der neue Chat öffnet sich automatisch und erscheint in der Seitenleiste. Eine Meldung nennt die Anzahl kopierter Nachrichten.

## Hinweise

- KI-Modell und Prompt-Einstellungen bleiben wie im Original.
- Lesezeichen werden nicht übernommen; alle Nachrichten sind zunächst unmarkiert.
- In **Meine Lesezeichen** ist das Verzweigungssymbol verborgen.
- Liegt das Original in einem Ordner, entsteht die Verzweigung im selben Ordner.
