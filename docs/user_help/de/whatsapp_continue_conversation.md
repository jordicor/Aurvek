## Kurzantwort

Weisen Sie einen Webchat im Seitenleistenmenü mit **Für WhatsApp verwenden** zu. Nachrichten an Aurveks WhatsApp-Nummer setzen dann diesen Chat fort.

## Schritte

1. Gewünschten Chat in der Seitenleiste finden.
2. Dreipunktmenü öffnen.
3. **Für WhatsApp verwenden** wählen.
4. Fehlt Ihre Telefonnummer, fordert ein Hinweis zum Eintragen in den Einstellungen auf.
5. Der Chat wandert nach **Extern** und erhält ein WhatsApp-Symbol.
6. Von Ihrem Telefon an Aurveks WhatsApp-Nummer schreiben; die Nachricht landet in diesem Chat.

Zum Beenden im selben Menü **Von WhatsApp entfernen** wählen.

## Hinweise

- Nur ein Chat kann WhatsApp zugewiesen sein; ein neuer löst den vorherigen automatisch ab.
- Ein Chat kann nicht gleichzeitig WhatsApp und Telegram nutzen. Eine Zuweisung entfernt die andere.
- Seine unabhängige Telefonzuweisung kann bleiben.
- Bei erstmaliger WhatsApp-Nutzung entsteht mit der ersten Nachricht automatisch ein Chat. Danach können Sie im Web einen vorhandenen Chat zuweisen.
- Nach Zuweisung im Chatmenü zwischen **Textmodus** und **Sprachmodus** wechseln. Sprachmodus sendet Audio statt Text.
- Direkt in WhatsApp zeigt `!chats` aktuelle Chats; `!set <id>` wechselt ohne Weboberfläche.
- WhatsApp-Nachrichten erscheinen im selben Verlauf im Web.
- Ist der zugewiesene Chat gesperrt, werden neue Nachrichten abgewiesen. Mit `!new` neu starten.
