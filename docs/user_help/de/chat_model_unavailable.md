## Kurzantwort

Deaktiviert ein Administrator ein Modell, bleiben vorhandene Chats lesbar. Ein Hinweis erklärt, dass neue Antworten damit nicht mehr möglich sind. Mit **KI-Modell ändern** setzen Sie denselben Chat mit einem verfügbaren Modell fort.

## Schritte

1. Chat öffnen und Hinweis oberhalb des Eingabefelds lesen.
2. **KI-Modell ändern** anklicken und im Chatkopf ein verfügbares Modell wählen.
3. Weiterchatten; frühere Nachrichten bleiben im Verlauf.
4. Wurde das Modell bei geöffnetem Chat deaktiviert, erklärt ein Sendeversuch das Problem und stellt den Entwurf wieder her. Modell wechseln und erneut senden; Dateien erneut anhängen, falls der Hinweis dazu auffordert.

## Hinweise

- Aurvek wählt kein Ersatzmodell automatisch.
- Manche Assistenten erfordern ein bestimmtes Modell oder begrenzen die Auswahl. Ist kein Wechsel möglich, kontaktieren Sie Ersteller oder Administrator.
- Deaktivierte Modelle sind für neue Chats und Vergleiche nicht auswählbar.
