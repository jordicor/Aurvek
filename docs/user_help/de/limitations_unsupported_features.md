## Kurzantwort

Aurvek läuft im Webbrowser. Einige bei anderen KI-Plattformen übliche Funktionen fehlen derzeit, darunter native mobile Apps, Offline-Zugriff und Self-Hosting für Endnutzer.

## Hinweise

- **Keine native App:** Nutzen Sie die responsive Web-App im mobilen Browser. Es gibt keine iOS-/Android-App.
- **Kein Offline-Modus:** Jede KI-Interaktion benötigt Internet.
- **Kein Self-Hosting für Endnutzer:** Aurvek ist ein gehosteter Dienst. Das GitHub-Repository richtet sich an Entwickler, die eigene Instanzen bereitstellen.
- **Keine Anhänge in Multi-AI/GranSabio:** Diese Modi unterstützen nur Text.
- **Keine Dokument-Uploads über WhatsApp/Telegram:** Unterstützt sind Bilder, Sprache und Text, keine Dokumentdateien.
- **Keine Video-Uploads:** KI-Videos lassen sich erzeugen, Videodateien aber nicht zur Analyse hochladen.
- **Keine Zusammenarbeit in Echtzeit:** Jede Unterhaltung gehört einem Nutzerkonto.
- **Keine allgemeine öffentliche Entwickler-API:** Integrierte Kanäle sind, sofern aktiviert, WhatsApp, Telegram und Telefon.
- **Keine externe Zuweisung für Inkognito-Chats:** Sie können weder Messaging- noch Telefonkanälen zugewiesen werden.
