## Kurzantwort

Multi-AI-Vergleich sendet eine Nachricht gleichzeitig an bis zu 4 KI-Modelle. Ihre Antworten erscheinen nebeneinander in einem Karussell, um verschiedene Antworten auf dieselbe Frage zu vergleichen.

## Schritte

1. **+** im Eingabebereich öffnen.
2. **Multi-KI-Vergleich** wählen, sofern für den Prompt verfügbar.
3. Im Dialog 2 bis 4 Modelle aus der gruppierten Liste auswählen.
4. Optional **Für alle folgenden Nachrichten aktiviert lassen** markieren, um den Modus für jede weitere Nachricht statt nur die nächste zu nutzen.
5. **Anwenden** anklicken; das Abzeichen zeigt die Modellanzahl.
6. Nachricht normal senden. Im Antwortkarussell mit Links-/Rechtspfeilen zwischen Modellantworten wechseln.
7. Zum Beenden den Dialog erneut öffnen und **Deaktivieren** wählen.

## Hinweise

- Mindestens 2, höchstens 4 Modelle pro Nachricht.
- Jede Modellantwort wird einzeln vom Guthaben abgerechnet.
- Antworten werden als eine Nachricht gespeichert und im PDF-Export berücksichtigt.
- Einzelne Antworten lassen sich über die Karussellaktionen kopieren, als Lesezeichen speichern oder anhören.
- Unterstützt die Prompt-Konfiguration die Funktion nicht, kann die Option fehlen.
