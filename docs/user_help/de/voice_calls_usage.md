## Kurzantwort

Sprechen Sie in Echtzeit über Ihr Browsermikrofon. Im Plus-Menü (+) **KI-Stimme** wählen, dann **Anruf starten**. **Ruf mich an** ist eine andere Funktion: Sie ruft Ihre gespeicherte Telefonnummer an.

## Schritte

1. Bestehenden Chat öffnen oder neuen beginnen.
2. **+** links unten an der Eingabe anklicken.
3. **KI-Stimme** wählen; das Sprachpanel erscheint.
4. Auf **Bereit zum Starten des Anrufs.** warten.
5. **Anruf starten** anklicken und ggf. Mikrofonzugriff erlauben.
6. Normal sprechen; der Status zeigt **Anruf aktiv**.
7. Mit der Mikrofontaste im Panel stumm-/lautschalten.
8. Abschließend **Anruf beenden** anklicken. Das System ruft das Transkript ab und speichert es im Chat.

## Hinweise

- Ein eingerichteter kompatibler Browser-Sprachagent ist erforderlich. Bei Nichtverfügbarkeit zeigt das Panel den Grund.
- Gesperrte Chats unterstützen keine Sprachanrufe.
- Mikrofonzugriff im Browser muss erlaubt sein.
- Nach Ende erscheinen Transkriptnachrichten im Verlauf; der Chat scrollt automatisch nach unten.
- Schlägt das Speichern fehl, lässt es sich im Sprachpanel erneut versuchen.
- Für echte eingehende/ausgehende Telefonanrufe siehe `phone_calls_usage`.
