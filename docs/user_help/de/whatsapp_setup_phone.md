## Kurzantwort

Für WhatsApp mit Aurvek hinterlegen und verifizieren Sie Ihre Telefonnummer in den Kontoeinstellungen. Sie muss der Nummer entsprechen, von der Sie WhatsApp-Nachrichten senden.

## Schritte

1. Im Hauptmenü **Einstellungen** oder **Profil bearbeiten** öffnen.
2. Unter Kontoinformationen **Telefonnummer** suchen.
3. Nummer eingeben. Die Landesvorwahl wird anhand Ihres Standorts gewählt und ist manuell änderbar.
4. **Bestätigungscode senden** anklicken; eine SMS geht an diese Nummer.
5. Code im erscheinenden Feld eingeben.
6. **Code überprüfen** anklicken. Ein korrekter Code bestätigt die Nummer.
7. Profil speichern, um Änderungen zu behalten.

## Hinweise

- Jede Nummer darf nur einem Konto zugeordnet sein. Bereits verwendete Nummern erfordern eine andere Nummer.
- Verlangt die Plattform Verifizierung für WhatsApp, sind Nachrichten erst danach möglich.
- Bei Zuweisung ohne Telefonnummer fordert ein Popup zum Hinzufügen in den Einstellungen auf.
- Speicherung im internationalen E.164-Format, z. B. +1234567890.
