## Kurzantwort

Hängen Sie unterstützte Bilder, PDFs sowie Text- oder Codedateien an. Nutzen Sie **+ > Dateien anhängen** oder fügen Sie ein Bild aus der Zwischenablage ein. Vor dem Senden erscheinen Vorschauen.

## Schritte

1. Eine geeignete Unterhaltung öffnen.
2. **+ > Dateien anhängen** öffnet die Dateiauswahl. Alternativ ein Bild direkt in den Chat einfügen (Ctrl+V oder Cmd+V).
3. Eine oder mehrere unterstützte Bild-, PDF-, Text-/Codedateien auswählen.
4. Oberhalb der Eingabe erscheint eine Vorschau: Miniaturbilder für Bilder, Dateinamen für andere Dateien.
5. Optional Nachricht eingeben und senden. Die KI verarbeitet Anhänge zusammen mit dem Text.

## Hinweise

- Aktuelle Größen- und Mengenlimits stehen in `limitations_file_types`.
- Das Modell muss den Anhang unterstützen. Multi-AI und GranSabio unterstützen nur Text.
- Einfügen aus der Zwischenablage funktioniert nur für Bildinhalte, nicht für PDFs.
