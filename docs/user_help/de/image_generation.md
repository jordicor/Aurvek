## Kurzantwort

Beschreiben Sie im Chat das gewünschte Bild. Die KI erkennt den Wunsch, erzeugt es und zeigt es direkt im Chat. Optional geben Sie ein Seitenverhältnis an.

## Schritte

1. Unterhaltung öffnen.
2. Wunsch beschreiben, etwa „Erzeuge ein Bild eines Sonnenuntergangs über dem Meer“ oder „Erstelle ein Porträt einer Katze mit Hut“.
3. Seitenverhältnis im Format `width:height` angeben. Unterstützt: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`. Beispiel: „Zeichne eine Berglandschaft 16:9“.
4. Senden. Währenddessen erscheint „Bild wird generiert…“.
5. Das fertige Bild erscheint im Chat.

## Hinweise

- Ausreichendes Guthaben ist erforderlich; sonst erscheint ein Fehler.
- Die KI entscheidet anhand des Nachrichtentexts. Natürliche Sprache genügt, kein spezieller Befehl ist nötig.
- Standard ohne Angabe: 1:1 (quadratisch).
- Je nach Engine dauert es einige Sekunden; bei zu langer Dauer erscheint eine Zeitüberschreitung.
- Das Bild wird im Chat gespeichert und ist später verfügbar.
