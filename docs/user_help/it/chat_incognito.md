## Risposta breve

Le chat in incognito non appaiono nella cronologia e vengono rimosse alla chiusura. Per conservarne una, premi **Salva chat** accanto al badge: diventa una normale chat nella stessa conversazione.

## Passaggi

1. Premi la freccia accanto a **Nuova chat**, quindi **Nuova chat privata**. Appare il badge **Privata**.
2. Usa normalmente le funzioni browser consentite da prompt e modello.
3. Per conservarla, attendi la fine della risposta e premi **Salva chat**. **Chat salvata. La modalità incognito è disattivata.** conferma.
4. Per chiudere senza salvare, premi X **Chiudi senza salvare**, cambia chat, creane una nuova o chiudi la scheda.

## Note

- Chiudere senza salvare elimina messaggi e file caricati e richiede la pulizia della memoria IA collegata.
- Salvare mantiene titolo, assistente, modello, messaggi e file; la chat entra nella cronologia e può andare in una cartella. Si applicano le normali impostazioni di memoria, che possono includere i messaggi precedenti.
- Una chat privata non compare nell’elenco, non legge ricordi tra chat e non può essere spostata, diramata né assegnata a WhatsApp, Telegram o telefono.
- Dopo una chiusura imprevista, i dati residui vengono puliti alla successiva apertura della chat.
