## Risposta breve

Aurvek usa un saldo, non abbonamenti fissi. Ogni messaggio costa un piccolo importo secondo modello e token. I modelli dipendono dal prompt e dai permessi: non esiste una lista separata «piano gratuito». Un saldo iniziale configurato dal creatore può permettere di iniziare senza aggiungere fondi.

## Passaggi

1. Scegli un prompt e un modello consentiti; ogni messaggio scala il costo dal saldo.
2. Se BYOK è abilitato, aggiungi chiavi OpenAI, Anthropic, Google o xAI e paga direttamente il provider senza costo API della piattaforma.

## Note

- I modelli economici costano frazioni di centesimo; quelli premium di più.
- Alcuni prompt offrono fino a $5 ai nuovi utenti registrati dalla loro pagina.
- Con BYOK, i prompt VIP richiedono ancora $0.10 di saldo per il margine del creatore.
- I creatori possono imporre un modello o una lista. Provider: OpenAI (GPT), Anthropic (Claude), Google (Gemini), xAI (Grok), OpenRouter.
- File, immagini, TTS e chiamate vocali sono permessi dell’account impostati dagli amministratori, indipendenti dal pagamento.
