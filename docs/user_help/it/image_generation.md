## Risposta breve

Descrivi naturalmente l’immagine desiderata in una conversazione; l’IA riconosce la richiesta e mostra il risultato nella chat. Puoi specificare le proporzioni.

## Passaggi

1. Apri una chat e descrivi l’immagine, per esempio «Genera un tramonto sull’oceano».
2. Aggiungi facoltativamente il formato `width:height` (larghezza:altezza). Formati supportati: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`.
3. Invia. Compare «Generazione immagine…», poi l’immagine appare nella conversazione.

## Note

- È necessario un saldo sufficiente.
- Non serve un comando: l’IA decide dal contenuto del messaggio.
- Senza indicazione usa `1:1` (quadrato).
- Il tempo dipende dal motore; se è eccessivo appare un timeout.
- L’immagine viene salvata nella conversazione.
