## Risposta breve

Esporta qualsiasi conversazione in PDF con messaggi utente e bot, Markdown formattato, immagini, blocchi di codice, tabelle e data/ora.

## Passaggi

1. Nel menu a tre punti della conversazione scegli **Scarica PDF**.
2. Conferma; la generazione viene accodata in background.
3. Al termine, apri la **Galleria multimediale** per trovare e scaricare il PDF.

## Note

- Puoi continuare a usare la chat durante l’elaborazione.
- Il nome contiene prompt e data/ora, per esempio `My_Prompt_2026_03_22_14_30_00.pdf`.
- Le immagini sono incorporate; se non più disponibili, compare un segnaposto.
- Le risposte Multi-IA sono incluse con l’etichetta di ogni modello.
- Se una generazione è già in corso, attendi alcuni minuti prima di ripeterla.
- Gli emoji usano il font Noto Emoji.
