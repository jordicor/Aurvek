## Risposta breve

Se un amministratore disabilita un modello, le conversazioni esistenti restano leggibili. Un avviso impedisce nuove risposte; usa **Cambia modello** per continuare nella stessa conversazione.

## Passaggi

1. Apri la chat e cerca l’avviso sopra il campo messaggio.
2. Premi **Cambia modello** e selezionane uno disponibile nell’intestazione.
3. Continua: i messaggi precedenti restano nella cronologia.
4. Se viene disabilitato mentre la chat è aperta, l’invio spiega il problema e ripristina la bozza. Cambia modello, ri-allega i file se richiesto e invia di nuovo.

## Note

- Aurvek non sceglie automaticamente un sostituto.
- Alcuni assistenti richiedono un modello o una lista limitata. Se non puoi sceglierne uno, contatta creatore o amministratore.
- I modelli disabilitati non sono selezionabili per nuove chat o confronti.
