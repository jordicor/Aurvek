## Risposta breve

Crea cartelle con nome e colore nella barra laterale, poi spostaci le conversazioni trascinandole o dal menu. Espandi una cartella per sfogliarne il contenuto.

## Passaggi

1. Premi **+** nella sezione Cartelle, assegna nome e colore e salva.
2. Trascina una conversazione sulla cartella o scegli **Sposta nella cartella** dal menu a tre punti.
3. Premi la cartella per espanderla o comprimerla. Dal menu puoi **Modificare** nome/colore o **Eliminare** la cartella.
4. Per estrarre una chat scegli **Rimuovi dalla cartella** o trascinala fuori. Eliminare la cartella riporta tutte le chat nell’elenco principale.

## Note

- Può essere espansa una sola cartella alla volta.
- Le chat nelle cartelle mantengono il menu normale: rinomina, PDF/MP3, elimina, ecc.
- Una nuova conversazione creata con una cartella selezionata nasce al suo interno.
- Il contenuto si carica a piccoli gruppi; se serve appare **Carica altro**.
