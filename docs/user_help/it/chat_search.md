## Risposta breve

La barra laterale cerca in tutte le tue conversazioni. I risultati raggruppati mostrano estratti evidenziati; un clic apre direttamente il messaggio.

## Passaggi

1. Inserisci almeno 3 caratteri in alto nella barra laterale e premi **Invio**.
2. Ogni risultato mostra conversazione, tipo utente/bot, data ed estratto evidenziato.
3. Premi un risultato per aprire la chat e raggiungere il messaggio evidenziato.
4. Usa **Carica altro** per il gruppo successivo; premi X o cancella il testo per uscire.

## Note

- La ricerca full-text FTS5 accetta frasi tra virgolette, per esempio `"visa interview"`.
- I risultati sono ordinati per pertinenza e caricati a gruppi di 30.
- La piccola x sull’evidenziazione la rimuove dalla chat.
- Vengono cercati solo i messaggi delle tue conversazioni.
