## Risposta breve

Allega immagini, PDF e file di testo o codice supportati con **+ > Allega file**, oppure incolla un’immagine dagli appunti. Prima dell’invio appare un’anteprima.

## Passaggi

1. Apri una conversazione idonea.
2. Premi **+ > Allega file**, oppure incolla un’immagine con Ctrl+V o Cmd+V.
3. Seleziona uno o più file supportati. Le immagini mostrano una miniatura, gli altri il nome.
4. Aggiungi facoltativamente del testo e invia; l’IA elabora gli allegati insieme al messaggio.

## Note

- I limiti correnti sono in `limitations_file_types`.
- Il modello deve supportare l’allegato. Multi-IA e GranSabio accettano solo testo.
- Dagli appunti si possono incollare immagini, non PDF.
