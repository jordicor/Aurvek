## Risposta breve

Il menu **+**, in basso a sinistra del campo, dà accesso ad allegati, registrazione audio, ragionamento, ricerca web, voce nel browser, telefono e confronto Multi-IA. Le voci dipendono da conversazione, modello, prompt e account.

## Passaggi

1. Premi **+** accanto al campo.
2. Scegli **Allega file** (immagini, PDF, testo/codice), **Registra audio** (trascrizione), **Ragionamento** (modalità ed eventuale intervallo token del modello), **Ricerca web** (interruttore, talvolta imposto o nascosto), **Voce IA** (microfono browser), **Chiamami** (numero verificato, ora o una volta più tardi) o **Confronto Multi-IA** (più risposte, se disponibile).
3. Clicca fuori o scegli un’opzione per chiudere.

## Note

- Permessi, prompt e modello determinano le opzioni visibili.
- **Voce IA** usa il browser; **Chiamami** la rete telefonica.
- Un piccolo punto appare sul **+** quando una funzione configurabile, come ragionamento, ricerca o Multi-IA, è attiva.
