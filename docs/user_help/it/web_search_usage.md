## Risposta breve

La ricerca web permette risposte aggiornate. Attiva per impostazione predefinita, si regola dal menu **+**. Fai semplicemente una domanda attuale; l’IA cerca automaticamente se necessario.

## Passaggi

1. Apri una conversazione e premi **+** in basso a sinistra.
2. Attiva o disattiva **Ricerca web**. La scelta resta salvata nell’account tra le sessioni.
3. Invia normalmente; se la ricerca è attiva e utile, l’IA consulta il web.

## Note

- Un prompt può imporre la ricerca (interruttore bloccato) o disabilitarla (voce nascosta).
- L’interruttore appare solo con una conversazione selezionata.
- Scegli Nativa o Perplexity nelle impostazioni; vedi `web_search_modes`.
- Le risposte possono includere citazioni delle fonti.
- Il pulsante **+** mostra un punto quando la ricerca o un’altra funzione è attiva.
