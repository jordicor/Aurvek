## Risposta breve

Aurvek è una piattaforma web nel browser. Attualmente non offre app mobile native, accesso offline né un’opzione self-hosted per utenti finali.

## Passaggi

1. Usa l’app web adattiva da un browser desktop o mobile con connessione Internet.
2. Per una funzione assente, considera i limiti seguenti prima di scegliere un altro flusso.

## Note

- Nessuna app iOS/Android, modalità offline o self-hosting utente; il repository GitHub è per sviluppatori che distribuiscono una propria istanza.
- Niente allegati in Multi-IA o GranSabio: solo testo.
- WhatsApp/Telegram supportano immagini, voce e testo, non documenti. I video si possono generare, ma non caricare per analisi.
- Nessuna collaborazione in tempo reale: ogni conversazione appartiene a un account.
- Nessuna API pubblica generale per sviluppatori. I canali integrati attivabili sono WhatsApp, Telegram e telefono.
- Le chat in incognito non si possono assegnare a canali esterni.
