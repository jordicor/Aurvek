## Risposta breve

Aurvek è una piattaforma di chat IA per browser desktop e mobile.

## Passaggi

1. Chatta con OpenAI, Anthropic, Google, xAI, MiniMax, Kimi e OpenRouter; cambia modello per conversazione.
2. Continua via WhatsApp o Telegram e, separatamente se disponibile, per telefono.
3. Carica immagini, PDF, testo o codice supportati; genera immagini e video Google VEO di 8 secondi con audio.
4. Ascolta con TTS, invia voce trascritta, usa **Voce IA** dal vivo o **Chiamami** al telefono.
5. Cerca sul web con motore nativo o Perplexity; esporta in PDF o MP3.
6. Organizza con cartelle, segnalibri e ricerca; dirama una chat o confronta 2-4 modelli con Multi-IA.
7. Scegli fra 13 temi e usa le tue chiavi API (BYOK) se consentito.

## Note

- L’uso misurato scala il saldo secondo modello e funzione; alcuni prompt offrono un saldo iniziale.
- Internet è obbligatorio; nessuna app mobile nativa né modalità offline.
- File, media, TTS, voce browser e telefono dipendono da account, prompt, modello e piattaforma.
