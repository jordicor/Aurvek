## Short answer

You can attach supported images, PDFs, and text or code files to a message. Use **+ > Attach files**, or paste an image from your clipboard. Attachments appear as previews before you send them.

## Steps

1. Open an eligible conversation.
2. To attach files, do one of the following:
   - Click the **+** button, then select **Attach files**. A file picker will open.
   - Paste an image from your clipboard directly into the chat (Ctrl+V or Cmd+V).
3. Select one or more supported images, PDFs, or text/code files.
4. A preview appears above the input. Images show a thumbnail; other files show their name.
5. Type your message (optional) and send. The AI will process the attached files along with your text.

## Notes

- Current size and quantity limits are listed in `limitations_file_types`.
- The selected model must support the attachment. Multi-AI and GranSabio conversations are text-only.
- Pasting images from the clipboard only works for image content, not PDF files.
