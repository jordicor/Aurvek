## Resposta breve

Aurvek reduz o lado maior da imagem para no máximo 1568 píxeis antes de a enviar à IA, mantendo a proporção e sem recortar. Só afeta imagens do chat, não fotografias de perfil, avatares ou fundos.

## Notas

- Para texto pequeno, recorte a zona; várias capturas focadas funcionam melhor.
- Aurvek guarda a versão reduzida e não mantém os bytes originais após a gravação.
- Não se aplica a imagens geradas por DALL-E, Ideogram, Gemini ou outros.
