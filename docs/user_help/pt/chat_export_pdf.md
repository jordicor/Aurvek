## Resposta breve

Pode exportar qualquer conversa para PDF com mensagens, Markdown formatado, imagens, código, tabelas e datas.

## Passos

1. Abra o menu de três pontos, escolha **Transferir PDF** e confirme.
2. A geração começa em segundo plano.
3. Quando terminar, abra a **Galeria multimédia** para transferir.

## Notas

- Pode continuar a usar o chat durante o processamento.
- O nome inclui prompt e data, por exemplo `My_Prompt_2026_03_22_14_30_00.pdf`.
- Imagens indisponíveis são substituídas por um marcador.
- Respostas Multi-IA aparecem separadas por modelo.
- Aguarde se já houver geração para a conversa.
- Emoji usa a fonte Noto Emoji.
