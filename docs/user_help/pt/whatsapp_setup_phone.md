## Resposta breve

Para usar WhatsApp, adicione e verifique nas Definições o mesmo número com que envia mensagens.

## Passos

1. Abra **Definições** ou **Editar perfil**.
2. Introduza o **Número de telefone**; o indicativo é sugerido, mas pode alterá-lo.
3. Clique **Enviar código de verificação**, introduza o SMS e clique **Verificar código**.
4. Guarde o perfil.

## Notas

- Cada número só pode associar uma conta.
- Se a verificação for obrigatória, não pode enviar até a concluir.
- Ao atribuir sem número, aparece um pedido para o adicionar.
- Guarda-se em formato E.164, por exemplo +1234567890.
