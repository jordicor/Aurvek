## Resposta breve

Escolha **Usar para WhatsApp** no menu lateral da conversa. Mensagens para o número WhatsApp de Aurvek continuam nela.

## Passos

1. Abra o menu de três pontos e escolha **Usar para WhatsApp**.
2. Se não houver telefone, adicione-o nas Definições.
3. A conversa passa para **Externos** com ícone WhatsApp.
4. Envie uma mensagem ao número Aurvek.

Para parar, escolha **Remover do WhatsApp**.

## Notas

- Só uma conversa pode estar atribuída; uma nova substitui-a.
- Não pode usar WhatsApp e Telegram ao mesmo tempo; telefone é separado.
- No primeiro uso pode ser criada uma conversa, depois reatribuível na web.
- Escolha **Modo de texto** ou **Modo de voz**; voz envia áudio.
- Use `!chats` e `!set <id>` diretamente no WhatsApp.
- Mensagens aparecem no mesmo histórico web.
- Se bloqueada, use `!new`.
