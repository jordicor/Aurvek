## Resposta breve

Fale em tempo real pelo microfone do navegador: abra **+**, escolha **Voz IA** e clique **Iniciar chamada**. **Ligar-me** faz uma chamada telefónica ao número guardado.

## Passos

1. Abra uma conversa, clique **+ > Voz IA** e aguarde **Pronto para iniciar a chamada**.
2. Clique **Iniciar chamada** e permita o microfone.
3. Fale; verá **Chamada ativa**. Use o botão para silenciar.
4. Clique **Terminar chamada**; a transcrição é guardada no chat.

## Notas

- Exige agente de voz de navegador compatível; o painel explica se faltar.
- Não funciona em conversas bloqueadas e requer permissão de microfone.
- Após terminar, as mensagens aparecem e o chat desloca-se ao fim.
- Pode repetir a gravação da transcrição no painel se falhar.
- Para telefone, consulte `phone_calls_usage`.
