## Resposta breve

Aurvek é uma plataforma web. Não oferece atualmente aplicações móveis nativas, acesso offline ou alojamento próprio para utilizadores finais, entre outras funcionalidades comuns.

## Notas

- Use a web adaptável no telemóvel; não há app iOS/Android.
- Todas as interações exigem Internet.
- O serviço é alojado; o repositório GitHub destina-se a programadores que implementam instâncias.
- Multi-IA e GranSabio só aceitam texto.
- WhatsApp/Telegram aceitam imagens, voz e texto, mas não documentos.
- Não há carregamento de vídeo para análise, embora possa gerar vídeo.
- Não há colaboração em tempo real; cada conversa pertence a uma conta.
- Não há API pública geral. Canais integrados incluem WhatsApp, Telegram e telefone quando ativos.
- Conversas incógnitas não podem ser atribuídas a canais externos.
