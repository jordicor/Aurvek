## Resposta breve

Crie pastas na barra lateral e arraste conversas para elas ou use o menu. Pode definir nome e cor e expandi-las.

## Passos

1. Clique **+** na secção Pastas, indique nome e cor e guarde.
2. Arraste uma conversa para a pasta ou use **Mover para pasta**.
3. Clique na pasta para expandir ou recolher.
4. Use **Editar** para nome/cor e **Remover da pasta** ou arraste para fora.
5. **Eliminar** apaga a pasta e devolve as conversas à lista principal.

## Notas

- Só uma pasta pode estar expandida.
- As conversas mantêm o mesmo menu contextual.
- Uma nova conversa criada com uma pasta expandida fica nessa pasta.
- O conteúdo carrega em lotes; **Carregar mais** aparece quando necessário.
