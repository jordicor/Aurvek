## Resposta breve

Anexe imagens, PDFs e ficheiros de texto ou código suportados com **+ > Anexar ficheiros**, ou cole uma imagem. Os anexos têm pré-visualização antes do envio.

## Passos

1. Abra uma conversa compatível.
2. Use **+ > Anexar ficheiros** ou cole uma imagem com Ctrl+V/Cmd+V.
3. Escolha ficheiros; imagens mostram miniatura e os restantes, o nome.
4. Escreva texto opcional e envie; a IA processa ambos.

## Notas

- Consulte os limites em `limitations_file_types`.
- O modelo deve suportar o anexo. Multi-IA e GranSabio só aceitam texto.
- Só imagens podem ser coladas; PDFs não.
