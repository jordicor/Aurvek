## Resposta breve

Se permitido, configure chaves em **Definições > Chaves de API** ou `/api-credentials`, escolha o armazenamento e guarde. Substituem as chaves padrão da plataforma.

## Passos

1. Abra **Definições > Chaves de API**.
2. Escolha **Apenas sessão**, **Persistente no navegador** ou **Armazenamento no servidor** cifrado.
3. Introduza chaves OpenAI, Anthropic, Google AI, xAI, MiniMax, Kimi ou ElevenLabs.
4. Use **Testar** numa chave, **Guardar tudo**, **Testar tudo**, **X** para remover uma ou **Limpar tudo**.

## Notas

- O administrador escolhe **Apenas chaves do sistema**, **Apenas chaves próprias**, **Ambas (preferir próprias)** ou **Ambas (preferir sistema)**.
- Com apenas chaves do sistema, não precisa de configurar.
- Se chaves próprias forem obrigatórias e faltarem, aparece um aviso.
- Cada fornecedor tem **Obter chave de API**.
