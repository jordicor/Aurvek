## Resposta breve

A pesquisa web fornece informação atual. Está ativa por defeito e muda-se em **+**. Faça uma pergunta atual e a IA pesquisa quando necessário.

## Passos

1. Abra uma conversa e clique **+**.
2. Use o interruptor **Pesquisa web**; a preferência fica guardada.
3. Envie normalmente; a IA pesquisa se precisar de informação atual.

## Notas

- Um prompt pode forçar a pesquisa; o interruptor fica bloqueado, ou oculto se desativada.
- Só aparece com conversa selecionada.
- Escolha Nativa ou Perplexity nas Definições; consulte `web_search_modes`.
- A resposta pode citar fontes.
- O botão **+** mostra um ponto com funcionalidades ativas.
