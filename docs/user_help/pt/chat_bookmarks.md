## Resposta breve

Pode marcar qualquer mensagem para acesso rápido. **Os meus marcadores** reúne-as por conversa.

## Passos

1. Passe sobre uma mensagem e clique no **ícone de marcador**; uma marca confirma.
2. Abra **Os meus marcadores** na barra lateral.
3. Clique num cabeçalho para abrir a conversa.
4. Clique novamente no marcador para o remover.

## Notas

- A conversa original mantém marcadores ao ramificar, mas a nova ramificação começa sem eles.
- Só mensagens já guardadas e com ID podem ser marcadas, não as que ainda estão a ser transmitidas.
- A vista é só de leitura, sem seletor de modelo ou campo de mensagem.
- Remover um marcador nessa vista retira imediatamente a mensagem.
