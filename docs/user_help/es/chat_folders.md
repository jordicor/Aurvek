## Respuesta breve

Puedes crear carpetas en la barra lateral para agrupar conversaciones. Arrastra una conversación a una carpeta o usa su menú. Las carpetas admiten nombres y colores propios y se pueden desplegar.

## Pasos

1. Pulsa **+** en la sección Carpetas.
2. Escribe un nombre, elige un color y guarda.
3. Arrastra una conversación a la carpeta o usa **Mover a carpeta** en el menú de tres puntos.
4. Pulsa la carpeta para desplegarla o contraerla.
5. Usa **Editar** en su menú para cambiar nombre o color.
6. Usa **Quitar de la carpeta** o arrastra el chat fuera para sacarlo.
7. Usa **Eliminar** para borrar la carpeta; sus conversaciones vuelven a la lista principal.

## Notas

- Solo puede haber una carpeta desplegada.
- Los chats dentro de carpetas tienen el mismo menú contextual que los demás.
- Si creas una conversación con una carpeta desplegada, se crea dentro de ella.
- Las conversaciones se cargan en lotes pequeños; si hay muchas, aparece **Cargar más**.
