## Respuesta breve

Aurvek es una plataforma de chat con IA para navegadores de escritorio y móvil.

## Pasos

1. Habla con modelos de OpenAI, Anthropic, Google, xAI, MiniMax, Kimi y OpenRouter, y cambia de modelo por conversación.
2. Continúa por WhatsApp o Telegram y, si está disponible, asigna de forma independiente una conversación a llamadas.
3. Sube imágenes, PDF y archivos de texto o código compatibles.
4. Genera imágenes con varios proveedores y proporciones.
5. Genera vídeos de 8 segundos con audio mediante Google VEO.
6. Escucha mensajes con TTS o envía voz transcrita automáticamente.
7. Habla en tiempo real con **Voz IA** en el navegador o usa **Llámame** por teléfono.
8. Busca información actual en la web con búsqueda nativa o Perplexity.
9. Exporta conversaciones a PDF o MP3.
10. Organiza chats con carpetas, marcadores, búsqueda y ramificaciones.
11. Compara entre 2 y 4 modelos con Multi-IA.
12. Elige entre 13 temas visuales.
13. Usa tus claves de API (BYOK), si está permitido.

## Notas

- El uso medido se descuenta del saldo según modelo y función.
- Algunos prompts ofrecen saldo inicial.
- Todo requiere Internet; no hay modo sin conexión ni app móvil nativa.
- Archivos, medios, TTS, voz del navegador y llamadas dependen de la cuenta, el prompt, el modelo y la plataforma.
