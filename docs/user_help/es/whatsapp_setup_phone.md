## Respuesta breve

Para usar WhatsApp, añade y verifica el teléfono en la configuración. Debe coincidir con el número desde el que enviarás mensajes.

## Pasos

1. Abre **Configuración** o **Editar perfil**.
2. Busca **Número de teléfono** en Información de la cuenta.
3. Introduce el número. El país se elige por ubicación, pero puedes cambiarlo.
4. Pulsa **Enviar código de verificación**; recibirás un SMS.
5. Escribe el código y pulsa **Verificar código**.
6. Guarda el perfil.

## Notas

- Cada número solo puede vincularse a una cuenta.
- Si se exige verificación para WhatsApp, no podrás enviar hasta completarla.
- Si asignas un chat sin teléfono, un aviso te dirige a Configuración.
- Se guarda en formato internacional E.164, por ejemplo +1234567890.
