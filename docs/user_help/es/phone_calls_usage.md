## Respuesta breve

Aurvek puede llamar ahora o a una hora programada al teléfono verificado de tu perfil. Si hay llamadas entrantes, puedes llamar desde ese número y continuar la conversación asignada. **Llámame** usa la red telefónica; **Voz IA**, el micrófono del navegador.

## Pasos

1. En **Configuración > Perfil**, verifica el teléfono. Una **Zona horaria** guardada ayuda a interpretar horas de llamada.
2. Abre la conversación y elige **+ > Llámame**.
3. Selecciona **Usar esta conversación para llamadas**; **Llamar ahora** y **Programar para más tarde** también la asignan.
4. Elige llamada inmediata o fecha y hora. El selector usa la zona del navegador y Aurvek solo llama al número guardado.
5. Si dispones de número de entrada, llama desde tu teléfono verificado; se usarán el prompt y el historial asignados.
6. Si el prompt lo permite, pide al asistente que llame ahora o programe una hora. Sin zona guardada puede pedir ciudad y país.
7. En **Configuración > Llamadas**, consulta el historial o cancela la llamada pendiente. Cualquiera puede finalizar una llamada activa.

## Notas

- Solo se asigna una conversación por cuenta; asignar otra la sustituye.
- El teléfono es independiente de WhatsApp y Telegram.
- Solo puede programarse una llamada futura, de una sola vez, no periódica.
- La transcripción se añade al chat. El audio bruto no se conserva salvo que el prompt lo habilite.
- Se requiere servicio disponible y saldo suficiente. Los chats bloqueados o de incógnito no pueden llamar.
