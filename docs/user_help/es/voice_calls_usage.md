## Respuesta breve

Puedes hablar en tiempo real con el micrófono del navegador. Abre **+**, elige **Voz IA** y pulsa **Iniciar llamada**. **Llámame** es distinto: llama al número guardado.

## Pasos

1. Abre o crea una conversación.
2. Pulsa **+** junto al campo de mensaje y elige **Voz IA**.
3. Espera a **Listo para iniciar la llamada**.
4. Pulsa **Iniciar llamada** y permite el micrófono si se solicita.
5. Habla normalmente; verás **Llamada activa**.
6. Usa el botón del micrófono para silenciarte o reactivarlo.
7. Pulsa **Finalizar llamada**; Aurvek recuperará y guardará la transcripción.

## Notas

- Requiere un agente de voz de navegador compatible; si falta, el panel explica el motivo.
- No funciona en conversaciones bloqueadas.
- El navegador debe permitir el micrófono.
- Al terminar, los mensajes transcritos aparecen en el historial y el chat baja al final.
- Si falla el guardado, puedes reintentarlo desde el panel.
- Para una llamada telefónica, consulta `phone_calls_usage`.
