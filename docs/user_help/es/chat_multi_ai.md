## Respuesta breve

Comparación Multi-IA envía un mensaje a entre 2 y 4 modelos a la vez y muestra las respuestas lado a lado en un carrusel.

## Pasos

1. Pulsa **+** junto al campo de mensaje.
2. Elige **Comparación Multi-IA**, si el prompt la admite.
3. Selecciona entre 2 y 4 modelos.
4. Si quieres mantener el modo, marca **Mantener activo para todos los mensajes siguientes**.
5. Pulsa **Aplicar**; la insignia muestra cuántos modelos hay seleccionados.
6. Envía el mensaje y recorre las respuestas con las flechas del carrusel.
7. Para desactivarlo, abre de nuevo el cuadro y pulsa **Desactivar**.

## Notas

- Se necesitan al menos 2 modelos y se admiten como máximo 4 por mensaje.
- Cada respuesta se cobra por separado del saldo.
- Las respuestas se guardan como un solo mensaje y se incluyen al exportar a PDF.
- Puedes copiar, marcar o escuchar cada respuesta desde sus iconos.
- La opción puede estar oculta si el prompt no la admite.
