## Respuesta breve

Puedes adjuntar imágenes, PDF y archivos de texto o código compatibles. Usa **+ > Adjuntar archivos** o pega una imagen del portapapeles. Verás una vista previa antes de enviar.

## Pasos

1. Abre una conversación compatible.
2. Pulsa **+ > Adjuntar archivos** o pega una imagen con Ctrl+V o Cmd+V.
3. Elige uno o varios archivos compatibles.
4. La vista previa muestra una miniatura para imágenes y el nombre para otros archivos.
5. Escribe un mensaje si quieres y envía; la IA procesará archivos y texto juntos.

## Notas

- Los límites actuales figuran en `limitations_file_types`.
- El modelo debe admitir el adjunto. Multi-IA y GranSabio solo admiten texto.
- El portapapeles solo permite pegar imágenes, no PDF.
