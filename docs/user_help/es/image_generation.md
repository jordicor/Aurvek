## Respuesta breve

Describe en un mensaje la imagen que quieres y la IA reconocerá la intención y la creará en el chat. Puedes indicar una relación de aspecto.

## Pasos

1. Abre una conversación.
2. Describe la imagen, por ejemplo: «Genera una imagen de una puesta de sol sobre el océano».
3. Para fijar la relación de aspecto, usa `width:height`. Se admiten `1:1`, `16:9`, `9:16`, `4:3` y `3:4`; por ejemplo, «Dibuja un paisaje de montañas 16:9».
4. Envía el mensaje. Aparecerá **Generando imagen...**.
5. La imagen aparecerá en el chat al terminar.

## Notas

- Necesitas saldo suficiente.
- La IA decide cuándo generar según el texto; no necesitas un comando especial.
- Si no indicas proporción, se usa 1:1.
- Puede tardar unos segundos; si tarda demasiado, aparecerá un aviso de tiempo agotado.
- La imagen se guarda en la conversación.
