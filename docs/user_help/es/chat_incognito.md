## Respuesta breve

Los chats de incógnito no aparecen en el historial y se eliminan al cerrarlos. Para conservar uno, pulsa **Guardar chat** junto a la insignia. Se convierte en un chat normal y puedes continuar en la misma conversación.

## Pasos

1. Pulsa la **flecha desplegable** junto a **Nuevo chat**.
2. Elige **Nuevo chat de incógnito**.
3. Aparece la insignia **Incógnito**.
4. Usa normalmente las funciones del navegador disponibles para el prompt y el modelo.
5. Para conservarlo, espera a que termine cualquier respuesta y pulsa **Guardar chat**. **Chat guardado. El modo incógnito está desactivado.** confirma el cambio.
6. Para cerrarlo sin guardar, pulsa la **X** (**Cerrar sin guardar**), cambia de conversación, crea otro chat o cierra la pestaña.

## Notas

- Cerrar sin guardar elimina mensajes y archivos y solicita limpiar la memoria de IA vinculada.
- Guardar conserva título, asistente, modelo, mensajes y archivos. El chat aparece en el historial y se puede mover a una carpeta.
- Un chat guardado sigue la configuración normal de memoria; sus mensajes anteriores pueden incluirse si está activada.
- Después de guardar, cambiar de chat o cerrar la pestaña conserva la conversación.
- Los chats de incógnito no aparecen en la lista ni en la barra lateral.
- No se pueden mover a carpetas, ramificar ni asignar a WhatsApp, Telegram o llamadas telefónicas.
- Si el navegador se cierra inesperadamente, los datos restantes se limpian al volver a abrir el chat.
- No leen tus recuerdos entre chats.
