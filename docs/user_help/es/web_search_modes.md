## Respuesta breve

Aurvek ofrece **Nativa** y **Perplexity**. La primera usa la búsqueda integrada del modelo y se recomienda a la mayoría; la segunda usa Perplexity AI. Puedes elegirlas en la configuración.

## Pasos

1. Abre **Configuración** desde el perfil.
2. Busca **Búsqueda web**.
3. Elige **Nativa (recomendada)**, más integrada y rápida, o **Perplexity**, que usa el servicio externo con sonar-pro y aparece desactivada si el servidor no la tiene configurada.
4. Guarda; se aplicará al siguiente mensaje.

## Notas

- La nativa funciona con Claude, GPT y xAI. Con modelos sin soporte, como Gemini, Aurvek recurre automáticamente a Perplexity.
- En modo nativo, el modelo busca e integra los resultados, a menudo con citas.
- Con Perplexity, la IA consulta la herramienta y luego redacta su respuesta en dos pasos.
- La preferencia vale para todos los chats; un prompt puede imponer búsqueda activa o inactiva.
