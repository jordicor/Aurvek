## Respuesta breve

Abre el bot de Aurvek en Telegram y comparte tu número cuando se solicite. El bot lo compara con tu cuenta de Aurvek y las vincula automáticamente.

## Pasos

1. Busca el bot de Aurvek en Telegram; pide su usuario al administrador si no lo conoces.
2. Pulsa **Iniciar** o envía un mensaje.
3. Pulsa **Compartir mi número de teléfono** cuando lo pida.
4. Confirma que quieres compartir el contacto.
5. Si el número coincide, verás un mensaje de bienvenida.
6. Ya puedes enviar texto, voz o fotos y recibir respuestas de IA.

## Notas

- Aurvek debe tener el mismo número registrado en Telegram.
- Debes compartir tu propio contacto; el bot comprueba el remitente.
- Cada Telegram solo puede vincularse a una cuenta; si ya pertenece a otra, aparece un error.
- Una cuenta de Aurvek desactivada no se puede vincular.
- Si el administrador exige verificación, verifica antes el teléfono en Aurvek.
- Al vincularse, el bot crea una conversación visible también en la web.
- Una conversación no puede estar en Telegram y WhatsApp a la vez; el teléfono es independiente.
- Usa `!help` para ver los comandos.
