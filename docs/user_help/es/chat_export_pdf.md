## Respuesta breve

Puedes exportar cualquier conversación a PDF. Incluye mensajes del usuario y del bot, Markdown renderizado, imágenes, bloques de código, tablas y marcas de tiempo.

## Pasos

1. Abre el menú de tres puntos de la conversación en la barra lateral.
2. Elige **Descargar PDF** y confirma.
3. Aurvek pone la generación en segundo plano y muestra un aviso.
4. Al terminar, abre la **Galería multimedia** para descargar el PDF.

## Notas

- Puedes seguir usando el chat mientras se genera.
- El nombre incluye el prompt y una marca de tiempo, por ejemplo `My_Prompt_2026_03_22_14_30_00.pdf`.
- Las imágenes se incrustan; si ya no están disponibles, se muestra un marcador.
- Las respuestas de comparación Multi-IA aparecen por separado con su modelo.
- Si ya hay una generación en curso, espera unos minutos antes de pedir otra para la misma conversación.
- Los emojis se representan con la fuente Noto Emoji.
