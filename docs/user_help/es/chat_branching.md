## Respuesta breve

Puedes ramificar una conversación desde cualquier mensaje para crear otra independiente con todos los mensajes hasta ese punto. Así exploras otra dirección sin perder el hilo original.

## Pasos

1. Pasa el puntero sobre cualquier mensaje.
2. Pulsa el **icono de ramificación** entre las acciones.
3. Confirma que quieres crear una conversación desde ese mensaje.
4. Se copiarán todos los mensajes hasta el seleccionado, incluido.
5. La nueva conversación se abre, aparece en la barra lateral y un aviso indica cuántos mensajes se copiaron.

## Notas

- La rama conserva el modelo de IA y la configuración del prompt.
- Los marcadores no se copian.
- El icono no aparece en **Mis marcadores**.
- Si la conversación original está en una carpeta, la rama se crea en ella.
