## Respuesta breve

Puedes marcar cualquier mensaje para encontrarlo rápidamente después. **Mis marcadores** reúne todos los mensajes marcados, agrupados por conversación.

## Pasos

1. Pasa el puntero sobre un mensaje del usuario o del bot.
2. Pulsa el **icono de marcador** (bandera). Una breve marca de verificación confirma el guardado.
3. Pulsa **Mis marcadores** en la barra lateral para verlos agrupados por conversación.
4. Pulsa la cabecera de una conversación para abrirla.
5. Para quitar un marcador, pasa el puntero sobre el mensaje y vuelve a pulsar el icono.

## Notas

- Los marcadores de la conversación original se conservan al ramificarla, pero la rama nueva empieza sin marcadores.
- Solo puedes marcar mensajes ya guardados y con ID; no mientras aún se transmiten.
- **Mis marcadores** es una vista de solo lectura, sin selector de modelo ni campo de mensaje.
- Al quitar un marcador desde esa vista, el mensaje desaparece de inmediato.
