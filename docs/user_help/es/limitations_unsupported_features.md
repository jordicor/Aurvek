## Respuesta breve

Aurvek es una plataforma web para navegadores. Actualmente no ofrece varias funciones habituales de otras plataformas de IA, como aplicaciones móviles nativas, acceso sin conexión o alojamiento propio para usuarios finales.

## Notas

- **Sin app móvil nativa:** usa la web adaptable en el navegador; no hay app para iOS o Android.
- **Sin modo sin conexión:** toda interacción con IA necesita Internet.
- **Sin alojamiento propio para usuarios finales:** es un servicio alojado; el repositorio de GitHub sirve a desarrolladores que despliegan su instancia.
- Multi-IA y GranSabio solo admiten texto, sin archivos.
- WhatsApp y Telegram admiten imágenes, voz y texto, pero no documentos.
- No se pueden subir vídeos para analizarlos, aunque sí generar vídeos con IA.
- No hay colaboración en tiempo real; cada conversación pertenece a una cuenta.
- No hay API pública general para desarrolladores. Los canales integrados, si están habilitados, son WhatsApp, Telegram y teléfono.
- Los chats de incógnito no se pueden asignar a canales externos.
