## Respuesta breve

Si un administrador desactiva un modelo de IA, las conversaciones existentes siguen siendo legibles. Un aviso indica que ya no puede responder. Usa **Cambiar modelo** para continuar la misma conversación con uno disponible.

## Pasos

1. Abre la conversación y busca el aviso sobre el campo de mensaje.
2. Pulsa **Cambiar modelo** y elige uno disponible en la cabecera.
3. Continúa; los mensajes anteriores permanecen en el historial.
4. Si se desactivó mientras el chat estaba abierto, un intento de envío explicará el problema y recuperará el borrador. Cambia de modelo, vuelve a enviar y adjunta otra vez los archivos si el aviso lo pide.

## Notas

- Aurvek no elige automáticamente un modelo sustituto.
- Algunos asistentes exigen un modelo concreto o limitan la selección. Si no puedes elegir otro, contacta con su creador o con el administrador.
- Los modelos desactivados no se pueden elegir para chats ni comparaciones nuevos.
