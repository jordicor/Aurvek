## Respuesta breve

La búsqueda web permite usar información actual de Internet. Está activa por defecto y se cambia en **+**. Solo pregunta algo actual y la IA buscará automáticamente cuando haga falta.

## Pasos

1. Abre una conversación.
2. Pulsa **+** abajo a la izquierda.
3. Busca **Búsqueda web** y usa el interruptor.
4. La preferencia se guarda entre sesiones.
5. Envía normalmente; si está activa y se necesita información actual, la IA buscará.

## Notas

- Un prompt puede imponerla activa o inactiva. Si la fuerza, el interruptor no se puede cambiar; si la desactiva, se oculta.
- Solo aparece con una conversación seleccionada.
- El motor Nativa o Perplexity se elige en Configuración; consulta `web_search_modes`.
- La respuesta puede incluir citas de fuentes.
- El botón **+** muestra un punto si esta u otra función está activa.
