## 要点

**LLM 管理**や**プロバイダーの同期**を開くと、24時間以上前のカタログを自動更新します。既存の利用可否と手動調整は維持され、新規モデルは無効で追加されます。結果はページ再読み込みなしで表示されます。

## 手順

1. **すべてのモデル**を開き、確認後にプロバイダー、名前、画像認識、利用可否で絞り込みます。
2. 行または**表示中のすべてのモデルを選択**を選び、**選択したモデルを有効化**／**選択したモデルを無効化**を押します。行のスイッチも即時保存します。
3. フィルター、並び順、ページ位置は維持されます。条件から外れた行は非表示になり、選択も解除されます。
4. **プロバイダーの同期**でプロバイダーを選び、**新規**、**更新あり**、**最新**、**ローカルのみ**の件数とフィルターを確認します。
5. **更新を確認**で自動更新後のリリースを検出します。**カタログを更新**は新規モデルを無効で追加し、メタデータを即時更新します。**新規**は「すべてのモデル」に未追加という意味です。
6. 同期画面で利用可否を変えるにはモデルを選択／解除し、**変更を保存**を押します。カタログ更新前に未保存の編集を戻すには**変更を元に戻す**を使います。

## 注意事項

- 同期モデルは無効化できますが、削除できるのは手動モデルのみです。
- **要確認**はメタデータ不足です。有効化前に料金を確認してください。
- 更新日はセッション間で共有します。失敗したプロバイダーは保存済みカタログを維持し、1時間後の再訪時または即時の手動更新で再試行できます。
- 連携アカウントのモデルなど、自動管理モデルはここで切り替えられません。
- プロバイダーの応答にないモデルは「ローカルのみ」になりますが、自動削除や利用可否の変更は行いません。
