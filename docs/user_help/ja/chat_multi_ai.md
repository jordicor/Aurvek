## 要点

Multi-AI比較では1つのメッセージを最大4つのAIモデルへ同時に送り、カルーセルで回答を見比べられます。同じ質問への対応の違いを確認できます。

## 手順

1. 入力欄の**+**を押します。
2. 利用可能なら**複数AI比較**を選びます。
3. ダイアログのグループ別一覧から2～4モデルを選びます。
4. 次の1通だけでなく以後すべてに使う場合は、**以降のすべてのメッセージで有効にする**を選びます。
5. **適用**を押します。ボタンのバッジに選択モデル数が表示されます。
6. 通常どおり入力して送信します。回答カルーセルの左右矢印でモデルごとの回答を切り替えます。
7. 終了するには同じダイアログで**無効にする**を押します。

## 注意事項

- 有効化には最低2モデルが必要で、1メッセージあたり最大4モデルです。
- 各モデルの回答はそれぞれ残高から課金されます。
- 比較の回答は1つのメッセージとして保存され、PDFにも含まれます。
- カルーセルの操作アイコンで個々の回答をコピー、ブックマーク、読み上げできます。
- プロンプト設定で非対応なら、この選択肢は表示されない場合があります。
