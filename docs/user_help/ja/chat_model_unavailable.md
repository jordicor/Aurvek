## 要点

管理者がAIモデルを無効にしても、既存の会話は読めます。新しい返答に使えないという通知が表示されます。**AIモデルを変更**で利用可能なモデルを選ぶと、同じ会話を続けられます。

## 手順

1. 会話を開き、入力欄の上のモデル利用不可の通知を確認します。
2. **AIモデルを変更**を押し、チャット上部から利用可能なモデルを選びます。
3. 会話を続けます。過去のメッセージは履歴に残ります。
4. 開いている間に無効化された場合、送信時に理由が表示され、下書きが復元されます。モデルを変えて再送信し、通知で求められた場合はファイルを添付し直してください。

## 注意事項

- Aurvekが代わりのモデルを自動で選ぶことはありません。
- 特定のモデル必須または選択肢が限られたアシスタントもあります。変更できなければ作成者か管理者に相談してください。
- 無効なモデルは新しい会話や比較には選択できません。
