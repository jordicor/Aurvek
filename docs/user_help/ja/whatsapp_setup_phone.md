## 要点

AurvekでWhatsAppを使うには、アカウント設定で電話番号を追加・認証します。WhatsApp送信に使う番号と一致している必要があります。

## 手順

1. メインメニューから**設定**（または**プロフィールを編集**）を開きます。
2. アカウント情報の**電話番号**欄を探します。
3. 電話番号を入力します。国番号は場所から自動選択されますが、手動で変更できます。
4. **認証コードを送信**を押すと、その番号にSMSが届きます。
5. 表示された欄にコードを入力します。
6. **コードを確認**を押し、正しければ番号が認証されます。
7. プロフィールを保存します。

## 注意事項

- 1つの番号は1つのアカウントにだけ連携できます。使用済みなら別の番号が必要です。
- WhatsApp利用に電話認証が必須の場合、完了まで送信できません。
- 番号なしで会話を割り当てようとすると、設定で追加するようポップアップが表示されます。
- 番号はE.164国際形式（例：+1234567890）で保存されます。
