## 要点

シークレットチャットは履歴に表示されず、閉じると削除されます。残すにはバッジ横の**チャットを保存**を押します。通常の履歴に入り、同じ会話を続けられます。

## 手順

1. サイドバーの「新しいチャット」横の**下向き矢印**を押します。
2. **新しいシークレットチャット**（探偵のアイコン）を選びます。
3. 上部に**シークレット**バッジが表示されます。
4. そのプロンプトとモデルで利用できるブラウザ機能を使い、通常どおり会話します。
5. 残すには、生成中の返答が終わるのを待ち、**チャットを保存**（ディスク）を押します。「チャットを保存しました。シークレットモードはオフです。」で確認できます。
6. 保存せず閉じるには、保存ボタン横の**保存せずに閉じる**（X）を押す、サイドバーで別の会話へ移る、新しいチャットを作る、またはブラウザタブを閉じます。

## 注意事項

- 保存せず閉じるとメッセージと添付ファイルが削除され、連携AIメモリの削除も依頼されます。
- 保存時はタイトル、アシスタント、モデル、メッセージ、添付ファイルを含む同じ会話が維持されます。通常の履歴に表示され、フォルダーへ移動できます。
- 保存後は通常のメモリ設定に従い、有効なら過去のメッセージもメモリに含まれる場合があります。
- 保存後に会話を切り替えたりタブを閉じたりしても履歴に残ります。
- シークレット中は会話一覧やサイドバーに表示されません。
- シークレット中はフォルダー移動、分岐、WhatsApp／Telegram／電話への割り当てはできません。
- ブラウザが異常終了した場合、次にチャットを開いた際に残ったデータを自動削除します。
- シークレットチャットは会話間で共有するメモリを読みません。
