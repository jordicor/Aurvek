## 要点

マイクで録音した音声を自動で文字起こしし、通常のチャットメッセージとして送れます。マイクボタンで録音を開始し、送信またはキャンセルします。

## 手順

1. 入力欄の横の**マイクアイコン**をクリックします。
2. ブラウザに求められたらマイクへのアクセスを許可します。
3. 入力欄が録音モードになり、タイマーと操作ボタンが表示されます。マイクアイコンは停止アイコンに変わります。
4. メッセージを話します。
5. **送信ボタン**（矢印）で録音を止め、文字起こしに送ります。**キャンセルボタン**（X）なら録音を破棄します。
6. サーバーで文字起こし後、テキストが入力欄に入り、チャットメッセージとして自動送信されます。

## 注意事項

- ブラウザに録音機能（MediaRecorder API）が必要です。通常の最新ブラウザは対応しています。
- マイク許可を以前拒否した場合は、ブラウザのサイト権限を変更してください。
- 録音形式はWebM、コーデックはOpusです。
- 文字起こしはアカウント残高を消費し、不足時は通知されます。
- 短い録音や無音では結果が空（204応答）になり、メッセージは送信されません。
- WhatsApp／Telegramの音声メモは外部チャネルの処理を使います。元の音声が保存されていれば、後から再文字起こしを依頼し、内容を確認・承認してから表示テキストを置き換えられます。
