## 要点

入力欄の左下にあるプラス（+）メニューから、添付、録音、推論、ウェブ検索、ブラウザ音声、電話、Multi-AI比較を使えます。項目は会話、モデル、プロンプト、アカウントによって変わります。

## 手順

1. 入力欄横の**+**で開きます。
2. 各項目を選びます。
   - **ファイルを添付**：対応画像、PDF、テキスト／コードを追加します。
   - **音声を録音**：マイクで録音し、文字起こしして入力欄へ入れます。
   - **推論**：現在のモデルが対応する推論モードを選びます。選択肢や任意指定のトークン範囲はモデルによります。
   - **ウェブ検索**：最新情報の検索をオン／オフにします。プロンプトによって常時オンか非表示の場合があります。
   - **AI音声**：ブラウザのマイクでリアルタイム音声会話を開始します。
   - **電話をかける**：会話を電話に割り当て、認証済みプロフィール番号へ今すぐまたは指定時刻に1回電話します。
   - **複数AI比較**：複数モデルへ同時送信し、回答を比較します。利用可能な会話のみ表示されます。
3. 項目を選ぶか外側を押すと閉じます。

## 注意事項

- モデル、プロンプト設定、アカウント権限により、常に全項目が表示されるとは限りません。
- **AI音声**はブラウザ、**電話をかける**は電話網を使います。
- 推論、検索、Multi-AIなどの設定可能な機能が有効なら、プラスボタンに小さな点が付きます。
