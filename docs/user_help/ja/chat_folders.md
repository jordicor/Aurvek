## 要点

サイドバーに名前と色を指定したフォルダーを作り、会話をまとめられます。ドラッグ＆ドロップまたは会話メニューで移動し、フォルダーを展開して中身を確認できます。

## 手順

1. サイドバーのフォルダー欄にある**+**を押します。
2. 名前と色を選んで保存します。
3. 会話一覧からフォルダーへドラッグするか、会話の三点メニューで**フォルダーに移動**を選びます。
4. フォルダーを押すと展開し、再度押すと折りたたみます。
5. 名前や色はフォルダーの三点メニューの**編集**で変更します。
6. 会話を外すには会話の三点メニューで**フォルダーから削除**を選ぶか、外へドラッグします。
7. フォルダーを消すにはその三点メニューの**削除**を選びます。中の会話は通常の会話一覧に戻ります。

## 注意事項

- 展開できるのは1つだけで、別のフォルダーを開くと前のものは閉じます。
- 内部の会話にも通常と同じメニュー（名前変更、PDF／MP3、削除など）があります。
- フォルダーを選択・展開した状態で新規会話を始めると、その中に作成されます。
- 会話は少しずつ読み込まれ、多い場合は下部に**さらに読み込む**が表示されます。
