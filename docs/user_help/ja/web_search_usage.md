## 要点

ウェブ検索により、AIがインターネットの最新情報を使って回答できます。標準で有効になっており、チャットのプラス（+）メニューで切り替えられます。特別な操作は不要で、最新情報が必要な質問をするとAIが自動で検索します。

## 手順

1. 会話を開きます。
2. 入力欄左下の**+**を押します。
3. **ウェブ検索**のスイッチを探します。
4. 押してオン／オフを切り替えます。設定はアカウントに保存され、次回以降も維持されます。
5. 通常どおりメッセージを送ります。有効な場合、AIが最新情報を必要と判断すると自動で検索します。

## 注意事項

- 常時オン／オフを強制するプロンプトもあります。オン強制時は有効表示のまま変更できず、無効の場合はスイッチ自体が非表示です。
- スイッチは会話選択中のみ表示されます。
- アカウント設定でネイティブとPerplexityを選べます。詳細は**web_search_modes**を参照してください。
- 検索時は回答に出典が付く場合があります。
- 検索などの機能が有効だと**+**に小さな点が付きます。
