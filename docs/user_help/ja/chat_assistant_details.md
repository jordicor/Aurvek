## 要点

チャット上部のアシスタントの写真または頭文字を押すと、**アシスタントの詳細**に画像、名前、説明、利用可能な拡張レベルが表示されます。パネルは現在のテーマに合わせて表示されます。

## 手順

1. 会話を開きます。
2. タイトル横の写真または頭文字を押します。**アシスタントの詳細を表示**ボタンはキーボードでも操作できます。
3. パネルの写真を押すと画像ビューアーで原寸画像が開きます。**Escape**または画像の外を押すと閉じます。
4. 詳細パネルは**閉じる**、**Escape**、パネル外のクリックで閉じ、会話の同じ位置に戻れます。

## 注意事項

- アシスタントカードは会話の冒頭にも表示されます。
- 長い会話は新しいメッセージから読み込まれます。上へスクロールして過去を読み込み、履歴の最初まで進むと最初のメッセージの上にカードが表示されます。
- 詳細パネルを開いても過去メッセージの読み込みやスクロール位置の変更はありません。
