## 要点

ブラウザのマイクでリアルタイムに会話できます。プラス（+）メニューで**AI音声**を選び、**通話を開始**を押します。保存した電話番号に電話する**電話をかける**とは別機能です。

## 手順

1. 既存の会話を開くか、新しく作ります。
2. 入力欄左下の**+**を押します。
3. **AI音声**を選ぶと通話パネルが開きます。
4. **通話を開始できます**という状態になるまで待ちます。
5. **通話を開始**を押し、未許可ならブラウザのマイク利用を許可します。
6. 普通に話します。通話中は**通話中**と表示されます。
7. パネルのマイクボタンで自分をミュート／解除できます。
8. 終わったら**通話を終了**を押します。文字起こしが取得され、会話に保存されます。

## 注意事項

- 対応するブラウザ音声エージェントの設定が必要です。使えない場合はパネルに理由が表示されます。
- ロックされた会話では使えません。
- ブラウザのマイクアクセス許可が必要です。
- 終了後に文字起こしが履歴へ追加され、自動で最下部へスクロールします。
- 保存に失敗したらパネルから再試行できます。
- 電話で発信・着信する場合は`phone_calls_usage`を参照してください。
