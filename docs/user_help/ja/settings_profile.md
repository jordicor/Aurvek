## 要点

**設定 > プロフィール**で個人情報、電話、タイムゾーン、写真、声、別人格、パスワードを管理できます。この画面ではユーザー名とメールアドレスは変更できません。

## 手順

1. 右上のプロフィールメニューから**設定 > プロフィール**を開きます。
2. **ユーザー名**は恒久的な識別子です。**メールアドレス**もここでは読み取り専用で、別の認証付き変更手続きを使います。
3. 必要なら**電話番号**を編集します。変更した番号は届いたSMSコードで認証します。
4. **タイムゾーン**をプルダウンから選ぶか、**都市名で検索**を開いて都市名（必要ならカンマと国名も）を入力し、**検索**を押します。場所とタイムゾーンを確認して**使用**を押します。デバイスのタイムゾーンも使用できます。
5. 写真、**あなたについて**、**あなたの声**を管理します。あなたの声はメッセージ再生とMP3書き出しで自分を表し、アシスタントの声は変えません。
6. 必要なら**対話プロフィール**の別人格を選択・管理し、**ログイン後**の移動先を選びます。
7. パスワードログインが有効なら、**パスワードを変更**で現在のパスワードと8文字以上の新パスワードを入力します。
8. **変更を保存**を押します。

## 注意事項

- **残高**はここでは読み取り専用です。チャージは**利用状況**で行います。
- 検索するだけでは保存されません。都市の選択やデバイスからの検出でタイムゾーン欄に値が入ります。**変更を保存**を押してください。保存されたタイムゾーンがなければ、通話予約時に都市と国を尋ねる場合があります。
- **アカウントを削除**はアカウントを永久に削除します。
