## 要点

会話全体をMP3音声ファイルに書き出せます。終了した電話は、保存済みの連続録音を一度だけ使用し、両者の声、間、同時発話を保ちます。WhatsApp／Telegram音声メモなど、ほかの保存済み音声も会話順に並びます。利用できる音声がないメッセージだけを読み上げ音声（TTS）に変換します。

## 手順

1. サイドバーで対象会話の三点メニューを開きます。
2. **MP3をダウンロード**を選びます。
3. ダイアログで確認します。
4. バックグラウンドの生成キューに入り、開始の通知が表示されます。
5. 完了後、**メディアギャラリー**からMP3を探してダウンロードします。

## 注意事項

- 通話全体がこの会話だけに属し、そのメッセージが連続した一つのブロックである場合に通話全体の録音を使用します。それ以外の場合や録音が利用できない場合は、各メッセージの利用可能な音声を使用します。
- バックグラウンド生成の所要時間は会話の長さによります。
- 保存済みの電話音声と音声メモは元の声を維持します。音声がないボット／ユーザーメッセージには、プロンプトとアカウントに設定された声を使います。
- 特に長い個別録音は、安定して書き出すためTTSに切り替える場合があります。
- ファイル名はプロンプト名と日時です（例：`My_Prompt_2026_03_22_14_30_00.mp3`）。
- 同じ会話の生成が進行中なら、再依頼まで数分待つ必要があります。
- 残高を消費するのはTTSが必要な部分のみです。保存済みの元音声の再利用にTTS料金は追加されません。
