## 要点

サイドバーの検索欄で全会話を検索できます。一致部分を強調した抜粋が会話ごとに表示され、結果を押すとそのメッセージへ直接移動します。

## 手順

1. サイドバー上部の検索欄に3文字以上入力します。
2. **Enter**で検索します。
3. 通常の会話一覧の代わりに検索結果が表示されます。会話名、ユーザー／ボットの区別、日付、一致語を強調した抜粋が表示されます。
4. 結果を押すと会話が開き、該当メッセージまでスクロールして強調表示されます。
5. 続きがある場合は下部の**さらに読み込む**を押します。
6. 検索欄の**X**を押すか文字を消すと、通常のサイドバーに戻ります。

## 注意事項

- 全文検索FTS5を使います。引用符で囲んだ語句で完全一致を検索できます（例：`"visa interview"`）。
- 関連度順に30件ずつ読み込みます。
- チャット内の強調表示は小さな「x」で解除できます。
- 検索対象は自分の会話のメッセージのみです。
