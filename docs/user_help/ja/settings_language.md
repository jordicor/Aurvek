## 要点

**インターフェース言語**はメニュー、フォーム、プラットフォームの通知を変更します。アカウントメニューの**言語**サブメニューから、**テーマ**の横で選べます。**会話の主言語**とは別の設定です。主言語は会話から言語が分からない場合にアシスタントと音声認識を助けます。

## 手順

1. アカウントメニューを開き、**テーマ**の横にある**言語**を選びます。
2. 英語、スペイン語、日本語、フランス語、ポルトガル語、イタリア語、ドイツ語から選びます。言語名はそれぞれの言語で表示されます。
3. 選択はアカウントのUI設定としてすぐ保存され、**設定 > プロフィール**の選択欄もすぐ更新されます。安全なページ再読み込みですべての表示ラベルが反映されます。
4. 未保存の変更がある場合は、再読み込みを許可するまで保持されます。チャットでは、先に通話、録音、返信を完了するか、下書きと添付ファイルを削除または保存してから再読み込みしてください。
5. **設定 > プロフィール**からもインターフェース言語を選べます。必要ならそこで**会話の主言語**と他に使う言語を設定して保存します。主言語を空欄にすると自動検出します。

## 注意事項

- 画面言語の変更は既存の会話を翻訳せず、アシスタントの声も変更しません。
- アシスタントの指示に明示的な言語ルールがあれば優先されます。それ以外は現在の依頼や会話で返答言語が決まり、主言語は判断できない場合に使われます。
- 他アプリに埋め込まれたチャットは、そのアプリが画面言語を管理します。利用できる場合はアプリ側の言語設定を使ってください。チャット側に別の選択欄は不要です。
- プラットフォームのヘルプは会話の言語に従います。最新のヘルプが英語のみなら、アシスタントが会話の言語で説明できます。
