## 要点

**設定 > 利用状況**で残高と利用明細を確認できます。**残高を追加**または`/payment`から$5～$500を選び、Stripeで安全に支払えます。

## 手順

### 残高と利用状況
1. **設定 > 利用状況**を開きます。
2. 上部の**現在の残高**を確認します。
3. **期間**で7日、30日、90日、全期間を選びます。
4. 操作総数、トークン数、総支出、1日あたり平均費用を確認します。
5. **ストレージ**に添付・生成メディアの使用容量と、該当する場合の上限が表示されます。
6. **種類別の利用**にAIトークン、TTS、STT、画像、動画、ドメインなどの内訳が表示されます。
7. **支出の推移**は選択期間の日別費用です。
8. **最近のアクティビティ**は日別の操作数と費用です。

### チャージ
1. **残高を追加**または`/payment`を開きます。
2. $5、$10、$25、$50、$100、または$5～$500の任意額を選びます。
3. **割引コード**があれば入力し、**適用**で割引後の金額を確認します。
4. 最終支払額を確認します。
5. **Stripeで支払う**から安全な決済画面へ進みます。
6. 支払い後にAurvekへ戻ると、残高がすぐ加算されます。

## 注意事項

- 決済はStripeが処理し、Aurvekはカード情報を保存しません。
- 100%割引ならStripeへ移動せず、その場で残高が加算されます。
- 残高は米ドルの小数第3位まで表示されます（例：$12.450）。
- プロフィールの残高は読み取り専用です。入金は利用状況または`/payment`から行います。
- ストレージ上限はアカウント設定によります。保存済みの添付と生成メディアが容量に算入されます。
