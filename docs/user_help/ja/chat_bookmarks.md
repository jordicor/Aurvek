## 要点

会話内のメッセージをブックマークして、後から簡単に参照できます。すべてのブックマークは**自分のブックマーク**に会話ごとにまとめて表示されます。

## 手順

1. ユーザーまたはボットのメッセージにポインターを合わせ、操作アイコンを表示します。
2. **ブックマークアイコン**（旗）を押します。短いチェックマークのアニメーションで保存を確認できます。
3. サイドバーの**自分のブックマーク**を押すと、元の会話ごとに表示されます。
4. 会話の見出しを押すと、その会話へ移動します。
5. 解除するには、常時ブックマークアイコンが表示されているメッセージにポインターを合わせ、再度アイコンを押します。フェードアウトして解除されます。

## 注意事項

- 会話を分岐しても元のブックマークは維持されますが、新しい分岐には引き継がれません。
- 保存済みでメッセージIDがあるものだけをブックマークできます。応答の生成中はできません。
- **自分のブックマーク**は読み取り専用で、モデル選択とメッセージ入力は非表示です。
- この画面で解除すると、そのメッセージは一覧からすぐ消えます。
