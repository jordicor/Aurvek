## 要点

Aurvekは認証済みのプロフィール電話番号へ今すぐ、または指定日時に電話できます。着信対応が有効なら、その番号からAurvekに電話して割り当て済み会話を続けられます。**電話をかける**は電話網、**AI音声**はブラウザのマイクを使います。

## 手順

1. **設定 > プロフィール**で電話番号を認証します。**タイムゾーン**を保存すると、アシスタントが通話日時を解釈しやすくなります。
2. 対象の会話で**+ > 電話をかける**を開きます。
3. **この会話を電話に使用**を選びます。**今すぐ電話**と**後で予約**でも自動で割り当てられます。
4. 即時通話または日時を選びます。この日時選択はブラウザの現在のタイムゾーンを使います。電話先は保存済みプロフィール番号のみです。
5. アカウントに着信用番号があれば、認証済み番号からかけます。割り当て済み会話のプロンプトと履歴を使います。
6. プロンプトが許可していれば、自然な言葉でも即時通話や日時予約を頼めます。タイムゾーン未保存なら都市と国を尋ねる場合があります。
7. **設定 > 通話**で履歴確認や予約取消ができます。通話中は自分かアシスタントが終了できます。

## 注意事項

- 電話に割り当てられる会話は1アカウント1つで、新しい割り当てが前のものを置き換えます。
- 電話はWhatsApp／Telegramと独立しており、1つのメッセージチャネルと併用できます。
- 予約できる将来の通話は1件で、繰り返しではなく1回限りです。
- 文字起こしは会話に追加されます。原音は通常保存せず、プロンプトで明示的に保存を有効化できます。
- サービス提供と十分な残高が必要です。ロック中やシークレットの会話では開始・予約できません。
