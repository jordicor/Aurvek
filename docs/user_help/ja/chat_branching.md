## 要点

任意のメッセージから会話を分岐し、その時点までの全メッセージを含む独立した新しい会話を作れます。元の会話を残して別の方向を試せます。

## 手順

1. チャットのユーザーまたはボットのメッセージにポインターを合わせます。
2. 操作アイコンの**分岐アイコン**（コードの枝）を押します。
3. そのメッセージから新しい会話を作るか確認するダイアログが表示されます。
4. **確認**を押すと、選択したメッセージを含む、それまでの全メッセージが新しい会話にコピーされます。
5. 新しい会話が自動で開き、サイドバーに表示されます。コピー件数が通知されます。

## 注意事項

- AIモデルとプロンプト設定は元の会話と同じです。
- ブックマークは引き継がれず、未登録に戻ります。
- **自分のブックマーク**画面では分岐アイコンは表示されません。
- 元の会話がフォルダー内なら、分岐も同じフォルダーに作られます。
