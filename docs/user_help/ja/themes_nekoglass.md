## 要点

Neko Glassは最も細かく調整できるテーマです。変更可能な壁紙上に半透明ガラスのパネルを重ね、専用設定で壁紙、透明度、ぼかし、吹き出し色、文字色、表示幅などを調整できます。

## 手順

1. 右上のプロフィールメニューで**テーマ > Neko Glass**を選びます。
2. 画面右側の小さな**浮動ボタン**（パレット）から**ガラス設定**を開きます。
3. 5区分の変更がすぐ適用されます。
   - **レイアウト**：列幅、文字サイズ、吹き出しの丸み、ページ文字色。
   - **ガラス効果**：自分の壁紙（最大5 MB）、ガラスの色（白、チャコール、ミッドナイト、オーシャン、アメジスト、ローズ、任意色）、ぼかし、不透明度、壁紙の暗さ。
   - **ユーザーメッセージ**：吹き出し色（インディゴ、紫、ローズ、青緑、エメラルド、アンバー、任意色）、不透明度、文字色。
   - **ボットメッセージ**：吹き出し色（ホワイトフロスト、ダークグラス、スモーク、ブラッシュ、ラベンダー、ミント、任意色）、不透明度、文字色。
   - **UIアクセント**：ボタンとリンクの色（インディゴ、紫、青緑、ピンク、緑）。
4. 最下部の**すべてリセット**で初期設定へ戻し、自分の壁紙を削除できます。

## ガラス設定パネル

5つの区分は折りたためます。

### レイアウト
- **列幅**：狭い、標準、広い、さらに広い、全画面。
- **文字サイズ**（チャットのみ）：メッセージの大きさ。
- **吹き出しの丸み**（チャットのみ）：角張った形から完全な丸みまで。
- **ページ文字**（チャット以外）：明色、暗色、任意色。

### ガラス効果
- **壁紙**：最大5 MBの自分の画像または標準画像。自分の壁紙はアカウントに非公開で保存され、ログインすれば他端末でも使えます。
- **ガラスの色**：白、チャコール、ミッドナイト、オーシャン、アメジスト、ローズの6色か任意色。
- **ぼかしの強さ**：完全な透明から強いすりガラスまで。
- **ガラスの不透明度**：低いほど壁紙が透けます。
- **壁紙を暗くする**：明るい背景でも文字を読みやすくします。

### ユーザーメッセージ（チャットのみ）
- **吹き出し色**：インディゴ、紫、ローズ、青緑、エメラルド、アンバーか任意色。
- **吹き出しの不透明度**：自分のメッセージの透明感。
- **文字色**：白、クリーム、暗色、任意色。

### ボットメッセージ（チャットのみ）
ユーザー側と同じ操作で、読みやすいホワイトフロスト、ダークグラス、スモーク、ブラッシュ、ラベンダー、ミントを選べます。

### UIアクセント
**インターフェース色**はボタン、リンク、操作要素に適用されます。インディゴ、紫、青緑、ピンク、緑の5色です。

## すべてをリセット

パネル下部の**すべてリセット**で全設定が標準に戻り、自分の壁紙も削除され、元の外観に戻ります。

## 注意事項

- 調整値はブラウザに保存され、ブラウザの変更やデータ消去で初期化されます。壁紙はサーバー保存なので他端末でも維持されます。
- ガラス設定ボタンはNeko Glass使用中のみ表示されます。
- 吹き出し色、文字サイズ、丸みなどはチャットページだけの追加操作です。
