## 要点

会話のメッセージはスピーカーアイコンで聴けます。テキストを音声に変換し、ブラウザへリアルタイム配信します。以前再生した音声ならキャッシュからすぐ読み込みます。

## 手順

1. メッセージにポインターを合わせるか、ボットメッセージの操作欄を見て、**スピーカーアイコン**（音量）を押します。
2. 読み込み中は砂時計になります。
3. 再生が始まると**停止**アイコンになり、いつでも押して止められます。
4. 別のメッセージのスピーカーを押すと、現在の音声は自動停止します。

## 注意事項

- 最初にキャッシュを確認し、あれば再生成せず即時再生します。
- キャッシュがなければ生成しながらWebSocketで配信するため、メッセージ全体の処理が終わる前に再生が始まります。
- TTS生成ごとに残高を消費します。キャッシュの再生は無料です。
- 残高不足なら再生の代わりに通知されます。
- ユーザーとボットの両方を再生できます。声は送信者とプロンプトの音声設定によります。
