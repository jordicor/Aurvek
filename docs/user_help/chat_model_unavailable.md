## Short answer

If an administrator disables an AI model, existing conversations remain readable. A notice explains that the model is no longer available for new replies. Use **Change model** to continue in the same conversation with an available model.

## Steps

1. Open the conversation and look for the unavailable-model notice above the message box.
2. Click **Change model** and select an available model from the chat header.
3. Continue the conversation. Previous messages remain in its history.
4. If the model was disabled while your chat was already open, a send attempt explains the issue and restores your draft. Change models and send again; re-attach files if the notice asks you to.

## Notes

- Aurvek does not automatically choose a replacement model.
- Some assistants require a specific model or allow only a limited selection. If no replacement can be selected, contact the assistant's creator or your administrator.
- Disabled models cannot be selected for new chats or new comparisons.
