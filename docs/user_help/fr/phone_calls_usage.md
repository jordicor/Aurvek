## Réponse courte

Aurvek peut appeler maintenant ou plus tard le numéro vérifié de votre profil. Si les appels entrants sont activés, appelez Aurvek depuis ce numéro pour continuer la conversation affectée. **Appelez-moi** utilise le réseau téléphonique ; **Voix IA** le microphone du navigateur.

## Étapes

1. Vérifiez le numéro dans **Paramètres > Profil** et enregistrez de préférence un **Fuseau horaire**.
2. Dans la conversation, choisissez **+ > Appelez-moi**, puis **Utiliser cette conversation pour les appels**. **Appeler maintenant** ou **Planifier** l’affecte aussi.
3. Choisissez maintenant ou une date/heure ; le sélecteur utilise le fuseau actuel du navigateur et Aurvek appelle seulement le numéro du profil.
4. Si un numéro entrant est fourni, appelez-le depuis votre numéro vérifié ; le prompt et l’historique affectés sont utilisés.
5. Si le prompt l’autorise, demandez naturellement un appel. Sans fuseau enregistré, l’assistant peut demander ville et pays.
6. Consultez ou annulez l’appel futur dans **Paramètres > Appels**. Pendant l’appel, vous ou l’assistant pouvez raccrocher.

## Remarques

- Une conversation téléphonique active et un appel futur maximum par compte ; les appels sont uniques, pas récurrents.
- Le téléphone est indépendant de WhatsApp/Telegram.
- La transcription rejoint la conversation. L’audio brut n’est pas conservé par défaut, sauf activation explicite du prompt.
- Service disponible, solde suffisant et conversation non verrouillée/non privée sont requis.
