## Réponse courte

Pour WhatsApp, ajoutez et vérifiez dans les paramètres le même numéro que celui utilisé pour envoyer les messages.

## Étapes

1. Ouvrez **Paramètres** ou **Modifier le profil**, puis **Numéro de téléphone** sous Informations du compte.
2. Saisissez le numéro. Le code pays est détecté par emplacement mais reste modifiable.
3. Cliquez sur **Envoyer le code de vérification**, saisissez le SMS, puis **Vérifier le code**.
4. Enregistrez le profil.

## Remarques

- Un numéro ne peut être lié qu’à un compte ; s’il est utilisé, choisissez-en un autre.
- Si la plateforme exige la vérification pour WhatsApp, aucun message n’est possible avant celle-ci.
- Une tentative d’affectation sans numéro ouvre une demande d’ajout dans Paramètres.
- Le numéro est stocké au format international E.164, par exemple +1234567890.
