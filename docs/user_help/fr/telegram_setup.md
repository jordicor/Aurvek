## Réponse courte

Ouvrez le bot Aurvek dans Telegram et partagez votre numéro lorsqu’il le demande. Le bot le compare au compte Aurvek et effectue automatiquement la liaison.

## Étapes

1. Recherchez le bot Aurvek dans Telegram ; demandez son nom à l’administrateur si nécessaire.
2. Appuyez sur **Démarrer** ou envoyez un message, puis sur **Partager mon numéro de téléphone** et confirmez votre propre contact.
3. Si le numéro correspond, le message de bienvenue confirme la liaison.
4. Envoyez alors texte, messages vocaux ou photos et recevez les réponses IA.

## Remarques

- Le même numéro doit être enregistré sur Aurvek et Telegram, et le contact doit appartenir à l’expéditeur.
- Un compte Telegram ne peut être lié qu’à un compte Aurvek ; un compte Aurvek désactivé ne peut être lié.
- Si l’administrateur impose la vérification, vérifiez d’abord le téléphone dans Aurvek.
- La liaison crée automatiquement une conversation visible sur le web.
- Une conversation ne peut être affectée à WhatsApp et Telegram à la fois ; le téléphone reste indépendant.
- Après la liaison, tapez `!help`.
