## Réponse courte

La recherche web permet des réponses à jour. Active par défaut, elle se règle dans le menu **+**. Posez simplement une question actuelle ; l’IA recherche automatiquement si nécessaire.

## Étapes

1. Ouvrez une conversation puis **+** en bas à gauche.
2. Activez ou désactivez **Recherche web**. Le choix est enregistré dans le compte entre les sessions.
3. Envoyez normalement ; si la recherche est active et utile, l’IA consulte le web.

## Remarques

- Un prompt peut imposer la recherche (interrupteur verrouillé) ou l’interdire (option masquée).
- L’interrupteur apparaît seulement lorsqu’une conversation est sélectionnée.
- Choisissez Native ou Perplexity dans les paramètres ; voir `web_search_modes`.
- Les réponses peuvent contenir des citations de sources.
- Le bouton **+** montre un point lorsque la recherche ou une autre fonction est active.
