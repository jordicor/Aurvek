## Réponse courte

Aurvek utilise un solde, pas des abonnements fixes. Chaque message coûte un petit montant selon le modèle et les jetons. Les modèles dépendent du prompt et des permissions : il n’existe pas de liste distincte « offre gratuite ». Un solde initial configuré par le créateur permet parfois de commencer sans ajouter de fonds.

## Étapes

1. Choisissez un prompt et un modèle autorisés ; le coût est déduit du solde à chaque message.
2. Si BYOK est autorisé, ajoutez vos clés OpenAI, Anthropic, Google ou xAI pour payer directement le fournisseur sans coût API de plateforme.

## Remarques

- Les modèles économiques coûtent des fractions de centime ; les modèles premium davantage.
- Certains prompts accordent jusqu’à $5 aux nouveaux inscrits depuis leur page.
- Avec BYOK, un prompt VIP exige encore $0.10 de solde pour la marge du créateur.
- Les créateurs peuvent imposer un modèle ou une sélection. Fournisseurs : OpenAI (GPT), Anthropic (Claude), Google (Gemini), xAI (Grok) et OpenRouter.
- Fichiers, images, TTS et appels vocaux sont des permissions administratives du compte, indépendantes du paiement.
