## Réponse courte

Créez des dossiers nommés et colorés dans la barre latérale, puis déplacez-y les conversations par glisser-déposer ou par leur menu. Dépliez un dossier pour parcourir son contenu.

## Étapes

1. Cliquez sur **+** dans la section Dossiers, donnez un nom et une couleur, puis enregistrez.
2. Glissez une conversation sur un dossier ou choisissez **Déplacer vers un dossier** dans son menu à trois points.
3. Cliquez sur un dossier pour le déplier ou le replier. Son menu permet **Modifier** le nom/la couleur ou **Supprimer** le dossier.
4. Pour sortir une conversation, choisissez **Retirer du dossier** ou faites-la glisser dehors. Supprimer un dossier remet toutes ses conversations dans la liste principale.

## Remarques

- Un seul dossier peut être déplié à la fois.
- Les conversations d’un dossier gardent le menu normal : renommer, PDF/MP3, supprimer, etc.
- Une nouvelle conversation créée pendant qu’un dossier est sélectionné est placée dedans.
- Le contenu se charge par petits lots ; **Charger plus** apparaît si nécessaire.
