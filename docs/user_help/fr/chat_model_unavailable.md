## Réponse courte

Si un administrateur désactive un modèle, les conversations existantes restent lisibles. Un avis empêche les nouvelles réponses ; choisissez **Changer de modèle** pour continuer dans la même conversation.

## Étapes

1. Ouvrez la conversation et repérez l’avis au-dessus du champ de message.
2. Cliquez sur **Changer de modèle** et choisissez un modèle disponible dans l’en-tête.
3. Continuez : les anciens messages restent dans l’historique.
4. Si la désactivation survient pendant que le chat est ouvert, l’envoi explique le problème et restaure le brouillon. Changez de modèle, rattachez les fichiers si l’avis le demande, puis renvoyez.

## Remarques

- Aurvek ne choisit pas automatiquement de modèle de remplacement.
- Certains assistants imposent un modèle ou une liste limitée. Sans remplacement possible, contactez le créateur ou l’administrateur.
- Un modèle désactivé ne peut servir à une nouvelle discussion ni une nouvelle comparaison.
