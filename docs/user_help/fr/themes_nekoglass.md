## Réponse courte

Neko Glass transforme l’interface en panneaux translucides sur un fond modifiable. Son panneau règle fond, teinte, flou, opacité, bulles, texte, largeur et accent.

## Étapes

1. Choisissez **Neko Glass** dans le menu de profil, puis le bouton flottant à palette pour ouvrir **Réglages du verre**.
2. Les cinq sections s’appliquent immédiatement : disposition ; effet verre avec fond jusqu’à 5 MB ; messages utilisateur ; messages bot ; accent de l’interface.
3. **Tout réinitialiser** restaure les valeurs par défaut et retire le fond personnel.

## Détail des réglages

- **Disposition** : largeur Étroit/Moyen/Large/Plus large/Plein écran ; taille de police et rondeur des bulles dans le chat ; texte clair, sombre ou personnalisé hors chat.
- **Effet verre** : fond privé synchronisé sur les appareils connectés ; teinte White, Charcoal, Midnight, Ocean, Amethyst, Rose ou libre ; intensité du flou, opacité et assombrissement du fond.
- **Messages utilisateur** : Indigo, Purple, Rose, Teal, Emerald, Amber ou couleur libre ; opacité ; texte White, Cream, Dark ou libre.
- **Messages bot** : mêmes réglages avec White Frost, Dark Glass, Smoke, Blush, Lavender et Mint.
- **Accent UI** : Indigo, Purple, Teal, Pink ou Green pour boutons, liens et éléments interactifs.

## Remarques

- Les réglages sont dans le navigateur et reviennent aux valeurs par défaut si ses données sont effacées ou si vous changez de navigateur. Le fond personnel est sur le serveur et suit le compte.
- Le bouton n’apparaît que sous Neko Glass.
- Le chat offre en plus couleurs des bulles, taille du texte et rondeur.
