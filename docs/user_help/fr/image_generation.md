## Réponse courte

Décrivez naturellement l’image voulue dans une conversation ; l’IA reconnaît la demande et affiche l’image générée dans le chat. Vous pouvez préciser le rapport largeur-hauteur.

## Étapes

1. Ouvrez une conversation et décrivez l’image, par exemple « Génère un coucher de soleil sur l’océan ».
2. Ajoutez éventuellement le format `width:height` (largeur:hauteur). Rapports pris en charge : `1:1`, `16:9`, `9:16`, `4:3`, `3:4`.
3. Envoyez. L’état « Génération de l’image… » s’affiche, puis l’image apparaît dans la conversation.

## Remarques

- Un solde suffisant est nécessaire.
- Aucune commande spéciale : l’IA décide à partir du message.
- Sans indication, le rapport est `1:1` (carré).
- Le délai dépend du moteur ; un message d’expiration apparaît si l’attente est trop longue.
- L’image est enregistrée dans la conversation.
