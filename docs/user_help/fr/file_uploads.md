## Réponse courte

Joignez des images, PDF et fichiers texte ou de code pris en charge avec **+ > Joindre des fichiers**, ou collez une image du presse-papiers. Un aperçu apparaît avant l’envoi.

## Étapes

1. Ouvrez une conversation admissible.
2. Cliquez sur **+ > Joindre des fichiers**, ou collez une image avec Ctrl+V ou Cmd+V.
3. Sélectionnez un ou plusieurs fichiers compatibles. Les images affichent une miniature, les autres leur nom.
4. Ajoutez éventuellement du texte et envoyez ; l’IA traite les pièces jointes avec le message.

## Remarques

- Les limites actuelles figurent dans `limitations_file_types`.
- Le modèle doit prendre en charge la pièce jointe. Multi-IA et GranSabio acceptent uniquement du texte.
- Le collage depuis le presse-papiers accepte les images, pas les PDF.
