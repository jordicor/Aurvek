## Réponse courte

Aurvek est une plateforme web dans le navigateur. Elle ne propose actuellement ni application mobile native, ni accès hors ligne, ni option auto-hébergée destinée aux utilisateurs finaux.

## Étapes

1. Utilisez l’application web adaptative depuis un navigateur de bureau ou mobile avec une connexion Internet.
2. Pour une fonction absente, tenez compte des limites ci-dessous avant de choisir un autre flux.

## Remarques

- Pas d’application iOS/Android, de mode hors ligne ni d’auto-hébergement utilisateur ; le dépôt GitHub vise les développeurs qui déploient leur propre instance.
- Pas de pièces jointes en Multi-IA ou GranSabio ; texte seulement.
- WhatsApp/Telegram acceptent images, voix et texte, pas les documents. Aucun téléversement vidéo pour analyse, même si l’IA peut générer des vidéos.
- Pas de collaboration en temps réel : chaque conversation appartient à un compte.
- Pas d’API développeur publique générale. Les canaux intégrés activables sont WhatsApp, Telegram et le téléphone.
- Une discussion privée ne peut être affectée à un canal externe.
