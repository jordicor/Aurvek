## Réponse courte

Vous pouvez ajouter tout message aux favoris pour le retrouver rapidement. **Mes favoris** les regroupe par conversation.

## Étapes

1. Survolez un message utilisateur ou bot, puis cliquez sur l’**icône de favori** en forme de drapeau ; une coche confirme l’enregistrement.
2. Ouvrez **Mes favoris** dans la barre latérale. Cliquez sur l’en-tête d’une conversation pour y accéder.
3. Pour retirer un favori, survolez le message marqué et recliquez sur l’icône ; il disparaît avec une animation.

## Remarques

- Les favoris restent dans la conversation d’origine après une bifurcation, mais la nouvelle branche démarre sans favoris.
- Seuls les messages déjà enregistrés et dotés d’un ID peuvent être marqués ; pas un message encore en diffusion.
- Dans **Mes favoris**, le sélecteur de modèle et le champ de saisie sont masqués car la vue est en lecture seule.
- Retirer un favori depuis cette vue en retire immédiatement le message.
