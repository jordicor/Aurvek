## Réponse courte

Bifurquez depuis n’importe quel message pour créer une conversation indépendante contenant tous les messages jusqu’à celui-ci inclus. Vous explorez ainsi une autre direction sans perdre l’original.

## Étapes

1. Survolez un message utilisateur ou bot et cliquez sur l’**icône de branche**.
2. Confirmez la création. Tous les messages jusqu’au message choisi inclus sont copiés.
3. La nouvelle conversation s’ouvre, apparaît dans la barre latérale et une notification indique le nombre de messages copiés.

## Remarques

- La branche conserve le modèle d’IA et les paramètres du prompt.
- Les favoris ne sont pas copiés.
- L’icône n’apparaît pas dans **Mes favoris**.
- Si l’original est dans un dossier, la branche est créée dans ce même dossier.
