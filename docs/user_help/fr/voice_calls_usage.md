## Réponse courte

Parlez en temps réel via le microphone du navigateur : ouvrez **+**, choisissez **Voix IA**, puis **Démarrer l’appel**. **Appelez-moi** est différent et appelle votre numéro enregistré.

## Étapes

1. Ouvrez ou créez une conversation, puis **+ > Voix IA**.
2. Attendez **Prêt à démarrer l’appel**, cliquez sur **Démarrer l’appel** et autorisez le microphone.
3. Parlez pendant l’état **Appel actif** ; utilisez le bouton microphone pour couper/rétablir votre son.
4. Cliquez sur **Terminer l’appel**. Aurvek récupère et enregistre la transcription dans la conversation.

## Remarques

- Un agent vocal navigateur compatible doit être configuré ; sinon le panneau en explique la raison.
- Indisponible dans les conversations verrouillées ; le navigateur doit autoriser le microphone.
- Après l’appel, les messages transcrits apparaissent et le chat descend automatiquement. En cas d’échec, réessayez depuis le panneau.
- Pour le réseau téléphonique, consultez `phone_calls_usage`.
