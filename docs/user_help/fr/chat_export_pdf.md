## Réponse courte

Vous pouvez exporter toute conversation en PDF avec les messages utilisateur et bot, le Markdown mis en forme, les images, blocs de code, tableaux et horodatages.

## Étapes

1. Dans la barre latérale, ouvrez le menu à trois points de la conversation et choisissez **Télécharger le PDF**.
2. Confirmez ; la génération est mise en file d’attente en arrière-plan.
3. Une fois terminée, ouvrez la **Galerie multimédia** pour trouver et télécharger le PDF.

## Remarques

- Vous pouvez continuer à discuter pendant la génération.
- Le nom comprend le prompt et un horodatage, par exemple `My_Prompt_2026_03_22_14_30_00.pdf`.
- Les images sont intégrées ; une image indisponible est remplacée par un espace réservé.
- Les comparaisons Multi-IA sont incluses avec une étiquette par modèle.
- Si une génération est déjà en cours, attendez quelques minutes avant d’en demander une autre pour cette conversation.
- Les emoji utilisent la police Noto Emoji.
