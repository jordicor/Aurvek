## Réponse courte

La barre de recherche latérale parcourt toutes vos conversations. Les résultats groupés affichent des extraits surlignés ; un clic ouvre directement le message.

## Étapes

1. Saisissez au moins 3 caractères en haut de la barre latérale et appuyez sur **Entrée**.
2. Chaque résultat indique conversation, type utilisateur/bot, date et extrait surligné.
3. Cliquez sur un résultat pour ouvrir la conversation et surligner le message.
4. Utilisez **Charger plus** pour le lot suivant, puis le X ou effacez le texte pour quitter la recherche.

## Remarques

- La recherche plein texte FTS5 accepte les expressions entre guillemets, par exemple `"visa interview"`.
- Les résultats sont classés par pertinence et chargés par lots de 30.
- Le petit x du surlignage retire celui-ci dans la discussion.
- Seuls les messages de vos conversations sont renvoyés.
